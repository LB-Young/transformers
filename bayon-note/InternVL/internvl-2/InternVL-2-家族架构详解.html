01家族全景

InternVL 2.0 延续 InternVL 1.5 的 ViT–MLP–LLM 范式：视觉塔（InternViT）→ pixel shuffle → MLP 投影层 → 大语言模型。家族覆盖 1B（端侧）到 108B，视觉塔只有两档规格，语言底座则按尺寸在 7 种开源底座间选择——这就是 Progressive Scaling Strategy。

02端到端架构总览

输入图像先按宽高比切为若干 448×448 tile 并加一张缩略图；每 tile 过 InternViT 得 1024 维特征图，经 pixel shuffle 空间减半、通道翻两番，再由 MLP 投影到 896 维；所有视觉特征按图像顺序摊平，以 masked_scatter 写入输入序列中 <image> 占位处，与文本 token 一同送入 Qwen2 解码器。

03视觉编码器 InternViT

家族视觉塔两档：小尺寸（1B/2B/4B/8B）用 InternViT-300M-448px，大尺寸（26B+）用 InternViT-6B-448px-V1.5。本地 1B 为 300M 规格：hidden 1024、24 层、16 头（head_dim 64）、patch 14、intermediate 4096、gelu、qkv_bias、Pre-LN。

图 2：InternViT-300M 单层结构（本地 config 实参；select_layer=-1 取末层并去 CLS）

注意：本地 config 的 vision_config.model_type 字符串写 intern_vit_6b，但 hidden 1024 / 24 层 / 16 头 / intermediate 4096 全部是 InternViT-300M-448px 的数值规格——本文按数值事实区分两档，不被类型字符串误导。

04投影层与语言底座

Pixel shuffle 把空间分辨率减半、通道翻两番，不丢信息地把 token 数压到四分之一；MLP 投影层再把视觉特征对齐到 LLM 的 hidden 维度。

语言底座 Qwen2-0.5B-Instruct：hidden 896、24 层、14 个 Q 头配 2 个 KV 头（GQA，分组数 7）、intermediate 4864、SwiGLU 激活、RMSNorm（eps 1e-6）、RoPE（theta=1e6）、词表 151655、最大位置 32768。GQA 使 KV cache 体积为 MHA 的 1/7，是端侧 1B 模型的效率关键。家族更大尺寸依次换用 InternLM2-1.8B、Phi-3-mini、InternLM2.5-7B、InternLM2-20B、Yi-34B、Llama-3-70B，投影层与视觉接口保持不变。

05动态分辨率机制

动态高分辨率是 InternVL 1.5 引入、2.0 完整保留的机制：按输入宽高比在预定义比例集合（1:1、1:2、1:3、1:4、1:5、1:6、2:3、3:2…）中找最接近者，把图缩放到该比例下若干个 448×448 tile 的组合，再额外拼一张整图缩略图供全局感知。

图 3：动态分辨率 tile 机制（以 800×1300、命中 2:3 → 6 tile + 1 缩略图为例）

前向时 input_ids 过词嵌入得 (b, s, 896) 文本嵌入；由 input_ids == image_token 构造布尔掩码，把视觉支路输出 (N_tile×256, 896) 用 masked_scatter 写进掩码为真的位置，再送入 Qwen2 解码器（对应本地源码 modeling_internvl.py:613-668）。

06训练管线

两阶段训练 + Progressive Scaling Strategy：先对齐、再全参 SFT，小模型训好的视觉塔/投影作为大模型初始化参考，逐级扩展到 108B。

视觉塔
连续学习
InternViT 连续学习预训练：从 InternViT-300M / 6B 基座出发连续学习，成为 2.0 两档视觉塔（300M-448px、6B-448px-V1.5）。
Stage-1
多模态对齐预训练（只训 MLP）：ViT 与 LLM 冻结，只训投影层。数据扩展自 1.5 预训练集：caption / VQA / 检测 / grounding / OCR（PaddleOCR）/ 考题 / OmniCorpus。
Stage-2
监督微调 SFT（全参数）：放开 ViT + MLP + LLM。在 5M 双语集上新增视频（EgoTaskQA / Mementos / STAR / NTU RGB+D 等）、医疗（PMC-VQA / Slake / VQA-RAD 等）、手写票据（SROIE / FUNSD / POIE），ShareGPT-4o 替换 ShareGPT-4V；训练上下文 8k（沿用 1.5 Mini 系列设定）。
扩展
Progressive Scaling 1B → 108B：小尺寸（1B/2B/4B/8B）先训好，其权重作为更大模型的初始化参考；语言底座逐级增大，视觉塔连续学习、可跨底座复用，以较低成本完成全家族。

07版本演进：1.5 → 2.0

InternVL 1.5（arXiv:2404.16821，2024-04）三大改进为 InternViT-6B 连续学习、动态高分辨率 tile、高质量双语数据集；2.0 保留 ViT–MLP–LLM 母版与动态分辨率机制，把规模、底座与输入输出模态全面铺开。
