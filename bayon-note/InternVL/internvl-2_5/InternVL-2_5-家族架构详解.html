InternVL 2.5 家族架构详解

2024-12 发布 · ViT–MLP–LLM 家族 1B – 78B 本地 config：InternVL2_5-1B 视觉塔 300M/6B · 底座 Qwen2.5/InternLM2.5

InternVL 2.5 在 InternVL 2.0 的 ViT–MLP–LLM 架构上，同时做模型（model）、数据（data）、测试时扩展（test-time scaling）三方面升级。本页以本地 InternVL2_5-1B 的 legacy internvl_chat config.json 为实参锚点：视觉塔为 InternViT-300M-448px-V2.5（config 里 model_type 字符串虽为 intern_vit_6b，数值实为 300M 规格），语言底座为 Qwen2.5-0.5B-Instruct。一切数值标注来源。

本地模型目录 E:\models\model\InternVL2_5-1B\config.json，采用 legacy internvl_chat 格式：顶层为 llm_config + vision_config + 多模态预处理超参。

2端到端架构总览

图像按宽高行动态切成若干 448 tile（+1 缩略图）→ InternViT 编码 → pixel unshuffle 降采样 → 2 层 MLP 投影到 LLM 隐空间 → 与文本 embedding 拼接 → 因果 LLM 自回归生成。

3视觉编码器 InternViT

本地 1B 用 InternViT-300M-448px-V2.5：由 6B 教师模型余弦蒸馏得到的 0.3B 变体（24 层、hidden 1024、16 头、patch 14、标准 LayerNorm、无 QK-Norm），再用 NTP 损失在更丰富数据上增量预训练。6B 规格为 45 层、hidden 3200、25 头、带 QK-Norm 与 RMSNorm。

4投影层与语言底座

4.1 Pixel Unshuffle 与视觉 token 复算

按 config 与源码 pixel_shuffle(scale_factor=0.5)、get_image_features 逐项复算：

patch_grid = image_size / patch_size = 448 / 14 = 32 tokens_raw = 32 × 32 = 1024 （去 CLS：[:, 1:, :]） feat = (b, 32, 32, 1024) --pixel_shuffle(0.5)--> (b, 16, 16, 4096) tokens_tile = 16 × 16 = 256 （每 tile 256 token，维度 4096） MLP projector: 4096 → 896 （对齐 LLM hidden_size） max_visual_tokens = (12 + 1 thumbnail) × 256 = 3328
符号含义取值（本地 1B）
tokens_raw单 tile patch token 数32×32 = 1024
downsample_ratiopixel shuffle 下采样比0.5
tokens_tile单 tile 投影后 token 数16×16 = 256
dim_tile单 token 维度（shuffle 后）1024 / 0.5² = 4096
max_dynamic_patch + thumbnail最大 tile 数12 + 1 = 13
max visual tokens单图视觉 token 上限13×256 = 3328

5核心机制

5.1 动态分辨率与像素 tile

图像先按原始宽高比缩放到最近的 448 tile 整数倍网格；高分辨率图切成多个 tile，低分辨率图 tile 数少于上限；额外拼接一张整图缩略图保留全局视野。

5.2 token 流与图像占位 token 注入

embedding 阶段用 masked_scatter 把视觉特征替换序列中的图像占位 token；占位 token 数必须与视觉特征 token 数严格相等（源码 get_placeholder_mask 校验）。

6训练管线（三阶段）

单模型训练分三阶段，逐步解锁可训练参数；配合渐进式扩展策略（先用小 LLM 练 ViT，再迁移到大 LLM）。

Stage 1

MLP Warmup（仅 MLP 可训练）

冻结 ViT 与 LLM，先用动态高分辨率、对话格式预训练数据打通跨模态对齐；较高学习率。

Stage 1.5

ViT 增量学习（可选，ViT+MLP 可训练）

较低学习率增强视觉特征（多语言 OCR、数学图表）；训练一次后可复用于不同 LLM。

Stage 2

全量指令微调（ViT+MLP+LLM 全量）

高质量多模态指令数据，统一学习率；严格数据质量控制，抑制重复输出。

数据规模：1.5 为 5.1M → 2.0 为 7.3M → 2.5 翻倍到 16.3M（严格过滤异常重复样本）。InternVL2.5-78B 仅用约 120B token 训练（对比 Qwen2-VL 累计 1.4T）；测试时引入 CoT 思维链实现 test-time scaling，78B 在 MMMU 验证集成为首个超 70 分的开源模型。

7版本演进对比：InternVL 2.0 → 2.5

架构同构（ViT–MLP–LLM + 动态分辨率机制不变），升级集中在模型、数据、测试时扩展。
