InternVL-3 家族架构详解（1B–78B）

2025-04 发布 · ViT–MLP–LLM 范式 入口类 InternVLForConditionalGeneration 本地 config：InternVL3-1B-hf（transformers 原生 internvl 格式） 原生多模态预训练 · V2PE · 测试时扩展

InternVL3 是上海 AI Lab InternVL 系列第三代开放多模态大模型，家族共 7 个尺寸（1B–78B），统一遵循 ViT–MLP–LLM 三段式架构。本页以本地 E:\models\model\InternVL3-1B-hf 的 config.json、本地 transformers 源码 modeling_internvl.py 与论文 arXiv:2504.10479 为唯一依据：视觉塔取 InternViT-300M 或 InternViT-6B（均为 448px-V2.5），语言底座取 Qwen2.5 系列 base 模型，投影层为随机初始化的两层 MLP。

2端到端架构总览（以本地 1B 为主尺寸）

输入图像经动态分辨率切片 → 逐切片过 InternViT-300M → Pixel Unshuffle 压缩 token → 两层 MLP 投影进 LLM 残差流 → 在 embedding 层用视觉特征替换图像占位 token → Qwen2.5-0.5B 自回归解码。38B/78B 仅把视觉塔换成 InternViT-6B-V2.5。

源码路径：InternVLModel.__init__ 组装 vision_tower / projector / language_model（:530-536）；get_image_features（:543-587）；forward 中 embed_tokens 查表后 masked_scatter 替换（:634-652）。

3视觉编码器 InternViT-300M-448px-V2.5

448×448 切片 = (448/14)² = 32×32 = 1024 个 patch token + 1 个 CLS。V2.5 相对 1.5/2.x 时代的 InternViT 有三个 config 可证的新特性：LayerScale（init 0.1）、mean pooling、可学习绝对位置编码 + V2PE。

本地 config 佐证：attention_bias=true（qkv 带 bias）、layer_scale_init_value=0.1、use_mean_pooling=true（分类侧）、use_qk_norm=false、layer_norm_eps=1e-6。

4投影层与语言底座

4.1 Pixel Unshuffle：视觉 token 压到 1/4

沿用 InternVL2.5 的像素重组（论文 §2.1）：32×32 空间网格按 r=0.5 重组，空间减半、通道 ×4，每切片 1024 patch → 256 个视觉 token，与 image_seq_length=256 严格相等。

S = H / p = 448 / 14 = 32 n_tok = (S·r)² = (32×0.5)² = 256 d_out = d_v / r² = 1024 / 0.25 = 4096
源码 pixel_shuffle（:670-703）：空间维减半、通道维按 1/r² 扩张。

4.2 两层 MLP 投影器（随机初始化）

论文 §2.1：投影器为随机初始化的两层网络；源码（:485-500）结构固定：

hidden = LayerNorm(4096) out = Linear2( GELU( Linear1(hidden) ) ) Linear1: 4096 → 896 Linear2: 896 → 896
4096 = d_v/r²；896 = 语言模型 hidden_size。投影器把视觉特征送进 LLM 残差流空间。

4.3 语言底座 Qwen2.5-0.5B

HF 架构类 Qwen2ForCausalLM：hidden 896、24 层、14 个 Q 头 / 2 个 KV 头（GQA 分组数 7）、head_dim=64、SwiGLU（silu）intermediate 4864。

vocab 151674（嵌入与 lm_head 绑定）；RoPE θ=1e6 + dynamic 缩放 ×2；rms_norm_eps=1e-6。论文强调：LLM 一律用 base 模型初始化，不用 instruction-tuned 版本。

4.4 本地 1B 参数量自核算

视觉塔 ≈302M（每层 qkv 1024×3072 + out 1024² + MLP 2×1024×4096 ≈12.6M ×24）；LLM ≈494M（嵌入 151674×896≈135.9M + 每层注意力 ≈1.84M + MLP 每层 ≈13.06M ×24）；投影器 ≈4.5M。

合计 ≈0.80–0.9B，与论文 Table 1 的 0.9B 同量级。

5核心机制专节

5.1 动态分辨率切片（tile）与缩略图

图像不强制 resize 到固定尺寸：按宽高比动态切为若干 448×448 切片，另加整图缩略图补全全局视野。本地 preprocessor_config：max_patches=12、min_patches=1、size 448×448。

processing_internvl.py:148-150 把每个 占位展开为 256×切片数 个图像 token，并用 BOI/EOI 特殊 token 包裹。

5.2 视觉 token 流与 masked_scatter

文本侧写入 BOI、重复 N 次的图像占位 token（id=151667）与 EOI；forward 时 embed_tokens 查表后用占位 id 构造掩码，把 ViT 输出的 (B, 256N, 896) 特征写回占位位置（:646-652）。

源码同时校验：占位 token 总数 ×896 == 视觉特征元素数，不等即报错（:607-610）。视觉 token 只作条件上下文，不参与 loss。

5.3 原生多模态预训练目标

语言预训练与多模态对齐合并进同一预训练阶段：纯文本语料与多模态语料交错混合、全部参数联合优化；loss 只在文本 token 上计算。

L_text-only(θ) = − Σ wᵢ · log pθ(xᵢ | x₁..xᵢ₋1) # 求和仅取 xᵢ ∈ Text wᵢ = 1 / l^0.5 # square averaging
语料配比 文本:多模态 = 1:3；总 token 约 200B（文本 50B + 多模态 150B）。

5.4 V2PE 可变视觉位置编码

为支持更长多模态上下文引入 Variable Visual Position Encoding：视觉 token 位置增量 δ 可调，全文实验默认 δ=1；训练侧配合头并行与序列并行支持最长 32K token 序列。

本地 config 中 use_absolute_position_embeddings=true，V2PE 是在绝对位置编码之上叠加的机制。

6训练管线：原生预训练 → SFT → MPO → 测试时扩展

InternVL3 完整管线分三大训练阶段，外加推理期的测试时扩展策略（论文 §2.2–§2.4）。

阶段一
预训练

原生多模态预训练（Native Multimodal Pretraining）

约 200B token：文本 50B + 多模态 150B（配比 1:3）。文本与多模态语料单阶段交错联合训练，全部参数不冻结；loss 仅在文本 token 上，square averaging 加权。多模态语料在 InternVL2.5 语料（caption、QA、数学、图表、OCR、文档、多轮对话、医疗）基础上新增 GUI、工具调用、3D 场景、视频理解。

阶段二
SFT

监督微调（SFT）

样本量从 InternVL2.5 的 16.3M 扩到 21.7M。沿用 2.5 的随机 JPEG 压缩、square loss 重加权、多模态数据打包；新增工具调用、GUI、3D、长上下文、视频、科学图表、创意写作与多模态推理样本。

阶段三
MPO

混合偏好优化（Mixed Preference Optimization）

约 30 万偏好对（基于 MMPR v1.2），用 InternVL3-8B/38B/78B 的 SFT 版产出 rollout。损失 = DPO 偏好损失 + BCO 质量损失 + LM 生成损失，缓解训练-推理分布偏移，增强思维链推理（78B 推理均分 +4.1）。

推理期
测试时

测试时扩展（Test-Time Scaling）

Best-of-N 采样 + VisualPRM-8B 评审模型：对思维链每一步预测 +/− 并取概率作为步质量分，平均后选最优回答；小尺寸模型也能获得可观推理增益。基础设施：扩展 InternEVO 框架，同规模训练吞吐较 InternVL2.5 提升 50%–200%。

7版本演进对比：InternVL 2.5 → InternVL 3.0

InternVL2.5（arXiv:2412.05271）已引入原生多模态预训练雏形与像素 unshuffle；InternVL3.0 把范式收敛为完整的单阶段原生预训练，并升级视觉塔、语言底座与后训练/测试时策略。
