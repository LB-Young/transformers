YOLOS 家族架构详解

研读对象 models/yolos/（transformers 5.23.0.dev0）。YOLOS（You Only Look at One Sequence）是华中科技大学 Fang 等在 NeurIPS 2021 提出的目标检测模型：不需要 CNN 主干、也不需要 DETR 的 encoder-decoder 跨注意力——一个普通 ViT encoder + 100 个可学习 detection token 就够了，把检测重新表述为「读一个 token 序列」。它是第一个「纯 ViT、零 CNN 归纳偏置」的检测器。

1一句话定位

目标检测不需要 CNN 主干、也不需要 DETR 那套 encoder-decoder 跨注意力，一个普通 ViT encoder + 100 个可学习 detection token 就够了——把检测重新表述为「读一个 token 序列」，序列末尾的 detection token 直接输出集合式预测（分类 + 框回归）。历史意义：第一个「纯 ViT、零 CNN 归纳偏置」的检测器，用于验证 ViT 作为通用视觉 backbone 的边界。

4端到端架构总览

输入 512×864 → patch 16 → 1728 patch token；拼接 [CLS]×1 + patch×1728 + detection×100 = 1829 token 序列；12 层纯 ViT encoder（位置编码可插值 + 中间层再注入）；取末尾 100 个 detection token 过共享 MLP 头输出 N+1 类 logits 与归一化框。

5核心机制（对照代码）

5.1 Token 序列拼接（YolosEmbeddings :76）

[CLS]×1 + patch_tokens×1728 + detection_tokens×100  →  序列长度 1829
# cls_token：1 个可学习参数（1×1×768）
# detection_tokens：100 个可学习参数（1×100×768），相当于 DETR 的 object queries，
#   但完全靠自注意力与 patch token 交互
# 位置编码 position_embeddings 形状 (1, 1728+100+1, 768)，随分辨率插值后加性叠加

5.2 位置编码：可插值 + 中间层再注入

初始位置编码（InterpolateInitialPositionEmbeddings :118）：forward 时按实际 (height, width) 把 [CLS] 位置、patch 位置、detection 位置拆开，patch 部分用双线性插值缩放到目标网格再拼回——因此任意分辨率输入都能跑。

中间层位置编码（InterpolateMidPositionEmbeddings :147；YolosEncoder :419-427）：当 use_mid_position_embeddings=True，除最后一层外，每层输出后再叠加一次插值后的位置编码（共 11 组）——弥补深层自注意力对位置信息稀释的问题。

5.3 Patch 嵌入（YolosPatchEmbeddings :187）

Conv2d(3, 768, kernel_size=16, stride=16)，num_patches = (864//16)×(512//16) = 54×32 = 1728。

5.4 检测头（YolosForObjectDetection :534）

  1. self.vit = YolosModel(config, add_pooling_layer=False)（不加池化层）
  2. 取 encoder 最后输出的末尾 100 个 detection token（:609）：sequence_output[:, -100:, :]
  3. 两个共享 MLP 头（均为 3 层，input/hidden=768）：class_labels_classifier → num_labels + 1（含 no-object）；bbox_predictor → 4 维 (cx, cy, w, h)，sigmoid 归一化（:613）
  4. 辅助损失（auxiliary_loss=True 且给 labels 时，:618-621）：把每层 encoder 的中间输出过同一对头，生成 auxiliary_outputs（对齐 DETR 的 aux loss 设计）

6训练与损失（DETR 式集合预测）

环节要点
匈牙利二分匹配训练时把预测框与 GT 框做最优匹配，匹配代价 = class_cost×分类 + bbox_cost×L1 + giou_cost×GIoU（1/5/2）
损失匹配后的分类 CE + bbox L1 + GIoU，系数 5/2；eos_coefficient=0.1 压低 no-object 类对损失的影响
推理YolosImageProcessor.post_process_object_detection 把归一化框还原为像素坐标（支持阈值过滤 + top-k）

一分钟结论

维度要点
架构纯 ViT encoder（12L/768/12H）+ 100 个 detection token
输入512×864，patch 16 → 1728 patch + CLS + 100 det = 1829 token
关键技巧位置编码可插值；中间层再次注入位置编码
输出每 token：N+1 类 logits + (cx,cy,w,h) 归一化框
损失匈牙利匹配 + CE + L1 + GIoU（1/5/2，eos 0.1）
代码入口YolosModel（backbone）/ YolosForObjectDetection（检测）

与检测/多模态演进的关系：vs DETR（encoder-decoder + cross-attention 做集合预测），YOLOS 只用 encoder，detection token 通过与 patch token 的全自注意力完成信息聚合；后续 ViTDet、DINO 等进一步证明 ViT backbone 在检测上的潜力；「位置编码随分辨率插值」与 Qwen2-VL / SigLIP-2 NaFlex 的可变分辨率思想同源。
