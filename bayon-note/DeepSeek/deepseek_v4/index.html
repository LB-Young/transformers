DeepSeek-V4-Flash-Base 家族架构详解

对应官方仓库 deepseek-ai/DeepSeek-V4-Flash-Base（model_type deepseek_v4）。完整尺寸 DeepSeek-V4 主仓官方未公开发布（404，待确认）；以下数字以本官方 config 为准。

DeepseekV4ForCausalLM · hidden 4096 · 43 层 MQA（kv_head=1，head_dim=512）+ DSA（topk=512） mHC 超连接（hc_mult=4，Sinkhorn 20） 256 专家选 6 + 1 共享；前 3 层 Hash MoE 1M 上下文（1048576）· FP8 e4m3

本页以 V4-Flash-Base 官方 config（hf-mirror 逐字段核对）与 transformers 源码 models\deepseek_v4\ 为依据。它相对 V3 是一次架构重写：MQA 替代 MLA、mHC 超连接替代标准残差、Hash+Sparse 混合 MoE、注意力进一步稀疏到 top-512。

2端到端数据流总览

词嵌入 → 43×DecoderLayer（mHC 包裹 MQA+DSA 注意力 与 MoE；前 3 层 Hash MoE，后 40 层 Sparse MoE 256选6+共享1）→ RMSNorm → LM Head；MTP ×1。

3解码层解剖

DeepseekV4DecoderLayer（modeling_deepseek_v4.py:1137-1180）：与 V3 前置 RMSNorm 残差不同，V4 用 mHC 超连接（873-960）门控融合两个子层。FFN 前 3 层走 HashRouter（1086），其余走 SparseMoeBlock（1117）。

4核心机制

4.1 MQA 单 KV 头 + DSA + 滑动窗

64 Q 头共享 1 个 KV 头（MQA, head_dim=512） → Indexer 为每查询选 top-512 token + sliding_window=128 → Q/O 各做 1024 维低秩投影

4.2 mHC 超连接

可学习逐通道门（hc_mult=4 倍扩展 + Sinkhorn 20 次迭代归一化）替代标准残差相加，层间信息流按通道自适应加权。

4.3 Hash MoE + Sparse MoE 混合

前 3 层 HashRouter 按哈希定专家（免可学习路由），后 40 层可学习路由（sqrtsoftplus 打分、noaux_tc、top-6、scaling=1.5、o_groups=8）。

4.4 1M 上下文压缩

compress_ratios 逐层 HCA/CSA 压缩比（交替 4/128）+ YaRN factor=16 + compress_rope_theta=160000，外推到 1,048,576。

5注意力机制

MQA（kv_head=1，head_dim=512）+ DSA index_topk=512 + 滑窗 128；qk_rope 64 维；上下文 1,048,576。

6特殊 Token 与词表

bos/eos=0/1，vocab_size=129280（同 V3/R1）。
