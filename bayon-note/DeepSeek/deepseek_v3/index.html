2端到端数据流总览

文本 token → 词嵌入（129280×7168，解绑）→ 61×DecoderLayer（前 3 层 Dense / 后 58 层 MoE）→ 最终 RMSNorm → LM Head；另有 1 层 MTP 头。

3解码层解剖：DeepseekV3DecoderLayer

单 RMSNorm 前置残差块（源码 modeling_deepseek_v3.py:485-529）。FFN 子层按层号二选一：layer_idx<3 用 Dense SwiGLU，≥3 用 DeepSeekMoE。

residual = x
x = input_layernorm(x) → MLA → ⊕
x = post_attention_layernorm(x) → FFN/MoE → ⊕

4核心机制：MLA · DeepSeekMoE · aux-loss-free · MTP · FP8

4.1 MLA 多头潜在注意力（Q/KV 双低秩压缩）

Q 侧：hidden→q_a_proj(7168→1536)→RMSNorm→q_b_proj(1536→128头×192)；KV 侧：hidden→kv_a_proj(7168→512+64)，512 维过 RMSNorm 后由 kv_b_proj 还原逐头 K-nope/V，64 维 k_rot 走 RoPE。KV cache 只存 576 维压缩潜变量。

z_kv = W_DKV · x ; c = RMSNorm(z_kv) ; [K;V] = W_UKV · c
q = W_UQ · RMSNorm(W_AQ · x) ; K_rope = RoPE(k_rot)
Attn = softmax(q·kᵀ / √192 + mask) · v

4.2 DeepSeekMoE：256 细粒度路由专家 + 1 共享专家

路由专家每专家宽 2048（细粒度），每 token 选 8；共享专家宽 2048 常开、输出直接相加（源码 220-221）。

4.3 aux-loss-free 负载均衡（noaux_tc）

sigmoid 打分 + e_score_correction_bias 历史负载修正 + 分组（256 分 8 组、组内 top2 求和、选 4 组）内再选 8，无路由辅助损失（config topk_method=noaux_tc）。

4.4 MTP 与 FP8

num_nextn_predict_layers=1：训练时多预测一个未来 token，推理可作投机解码草稿头。quantization_config=fp8 e4m3 为训练/存储精度（128×128 块权重缩放、激活动态量化），不改架构拓扑。
