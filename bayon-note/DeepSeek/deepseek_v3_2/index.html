DeepSeek-V3.2-Exp 家族架构详解

DeepseekV32ForCausalLM · model_type deepseek_v32 注意力换 DSA 稀疏（index_topk=2048） 主干同 V3：MLA · 256 选 8 + 1 共享 671B-T37B · FP8 e4m3 · YaRN 163840

本页以 DeepSeek-V3.2-Exp 官方 config（hf-mirror 逐字段核对）与 transformers 源码 models\deepseek_v32\ 为依据。它在 V3 主干上只改注意力：用 Lightning Indexer 选出每查询 top-2048 token，主 MLA 只在稀疏子集上算注意力。

2端到端数据流总览

主干同 V3：词嵌入 → 61 层（前 3 Dense / 后 58 MoE）→ RMSNorm → LM Head；每层注意力换成「MLA + DSA 稀疏掩码」。

3解码层解剖

DeepseekV32DecoderLayer（modeling_deepseek_v32.py:601-643）与 V3 同构：前置 RMSNorm → 注意力 → 残差 → RMSNorm → FFN/MoE → 残差。

4核心机制：DSA 稀疏注意力（Lightning Indexer）

indexer(q_idx, k_idx) → 每查询 top-2048 个 token → 折成稀疏 attention mask → 主 MLA 在稀疏掩码上算注意力

Indexer（modeling:147-200）是与主 MLA 分离的轻量投影（64 头×128 维）；主注意力（335-478）把 top-k 掩码折进去。FFN 侧 MoE 同 V3。
