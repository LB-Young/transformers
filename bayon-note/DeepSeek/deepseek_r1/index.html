DeepSeek-R1 家族架构详解

DeepseekV3ForCausalLM · model_type deepseek_v3 671B-T37B · 与 V3 同底座（config 逐字段一致） 差异在训练：冷启动推理 SFT → 大规模 RL 输出 <think>...</think> 思维链 R1-Distill：Qwen2.5 / Llama3 小模型蒸馏

本页以 DeepSeek-R1 官方 config.json（hf-mirror 拉取，逐字段核对）为唯一依据：R1 与 V3 的架构字段完全一致，唯一顶层差异是 transformers_version。架构数字引用 V3 目录，R1 独有训练管线与推理行为。

2端到端数据流总览（同 V3）

文本 token → 词嵌入 → 61×DecoderLayer（前 3 Dense / 后 58 MoE，MLA）→ RMSNorm → LM Head；MTP ×1。本节只给 R1 的训练/行为差异。

3解码层解剖（同 V3）

与 V3 逐行一致（DeepseekV3DecoderLayer，前置 RMSNorm 残差块，FFN 子层前 3 层 Dense、后 58 层 MoE）。源码 models\deepseek_v3\modeling_deepseek_v3.py:485-529。

4核心机制：架构同 V3，差异在训练

4.1 与 V3 的差异是训练而非架构

V3 : 通用预训练 + 通用 SFT/RLHF → 通用对话
R1 : 同一 V3 权重底座
├ 冷启动 reasoning SFT（避免 RL 初期乱输出）
└ 大规模 RL（数学/代码准确率、格式、去重奖励）→ 激发长链推理

4.2 输出思维链 <think>...</think>

R1 先输出一段隐式思维链再正式作答（由 tokenizer_config 定义，config 顶层未单列 id）。这是输出格式约定，不是新增架构模块。

4.3 R1-Zero 对照

从 V3-Base 直接上 RL、不经冷启动 SFT 的对照版本，验证 RL 能否单独激发推理——与 R1 共用同一架构，仅训练流程少一步。

5注意力机制（同 V3）

MLA 低秩 KV（kv_lora_rank=512）、RoPE 仅作用 64 维段、YaRN factor=40 外推到 163840。详见 V3 目录 §5。
