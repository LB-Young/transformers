总览

前馈网络（Feed-Forward Network, FFN）是 Transformer 中与自注意力（Self-Attention）并列的两大子层之一：注意力负责 token 之间的信息混合，FFN 负责对每个 token 独立做非线性特征变换。

在原始 Transformer（2017）中，FFN 只是“两个线性层 + 中间 ReLU 激活”的简单堆叠，中间维度约为 d_model 的 4 倍[1]。但随着模型变大，FFN 逐渐成为参数与算力的主要承载者：在原始 Transformer 中，每层 FFN 的参数量约为注意力子层的 2 倍（FFN ≈ 8·d_model²，注意力 ≈ 4·d_model²），整层计算中 FFN 约占三分之二[1]。

过去九年，FFN 的演进沿三条主线展开：其一，激活函数从 ReLU 走向 GELU、再走向自门控的 SiLU/Swish 与 GLU 家族，最终 SwiGLU 成为 Llama、Mistral、Qwen、Gemma、PaLM 等主流模型的标配[2][4][5][6]；其二，结构从单条路径的两线性层，演化为 up/gate/down 三权重的门控 FFN，并出现 PaLM 式 attention 与 FFN 并行的单残差分支设计[6]；其三，自 2021 年 Switch Transformer 起，FFN 被整体复制为多个“专家”，经路由器选择性激活，FFN 成为稀疏混合专家（Mixture-of-Experts, MoE）的载体——从 Mixtral 的 8 大专家 Top-2，到 DeepSeek-V2/V3 的细粒度专家 + 共享专家，再到 2025-2026 年千亿至万亿参数级 MoE 成为主流旗舰形态[8][9][10][11]。

演进时间线

2017–2026：激活函数、FFN 结构与 MoE 路由三条线索的关键节点，关键节点附来源上标。

2017.6
原始 Transformer 的标准 FFN[1]
两层线性变换 + ReLU，中间维度 d_ff≈4·d_model（base 版 512→2048）；FFN 约占每层参数的三分之二。
2017.10
Swish / SiLU 自门控激活[4]
Google 提出 Swish（x·σ(x)），因形式上等价于 x 乘自身 sigmoid 门，又称自门控（self-gated）激活。
2018–2019
GELU 进入 Transformer[2][3]
GELU 论文 2016 年提出；GPT-2（2019）首次在 Transformer 中用 GELU 取代 ReLU，BERT 随后跟进。
2020.2
GLU 变体系统性对比[5]
Shazeer 提出 GLU/Bilinear/ReGLU/GeGLU/SwiGLU 一族门控激活，实验表明 SwiGLU/GeGLU 优于标准 FFN，为门控 FFN 定调。
2020.6
GShard：首个大规模 Top-2 MoE[7]
Google 将 FFN 复制为多个专家并做分片训练，600B 模型每 token 激活 2 个专家，验证 MoE 可扩展。
2021.1
Switch Transformer：Top-1 路由[8]
简化为每 token 只激活 1 个专家，训练成本减半，模型扩到 1.6T，使 MoE 成为社区共识路线。
2022.4
PaLM：并行 FFN + SwiGLU[6]
把 attention 与 FFN 放在同一残差分支并行计算（不再串行），FFN 用 SwiGLU；540B 模型验证并行结构可行。
2023.12
Mixtral 8×7B：开源稀疏 MoE 破圈[9]
8 个专家、Top-2 路由、共享注意力，总参数约 46.7B、每 token 激活约 12.9B；开源权重让 MoE 可被广泛复现。
2024.5
DeepSeek-V2：细粒度专家 + 共享专家[10]
236B 总参数/21B 激活；256 个细粒度路由专家（Top-6）外加 2 个共享专家——FFN 专家粒度首次大幅细化。
2024.12
DeepSeek-V3：无辅助损失负载均衡[11]
671B 总/37B 激活；256 路由专家 Top-8 + 1 共享专家，用路由 bias 代替辅助损失做负载均衡，标志国产 MoE 主线成熟。
2025.4
Qwen3 MoE 与 Llama 4[12][16]
Qwen3-235B-A22B：128 专家激活 8、取消共享专家、global-batch 负载均衡损失；Meta Llama 4 Maverick 首次在 Llama 系列采用 MoE（128 专家、400B/17B）。
2025.7
Kimi K2：万亿级开源 MoE[13]
1.04T 总参数/32B 激活，沿用 DeepSeek-V3 式架构（MLA + 专家 FFN），配合 MuonClip 优化器零 loss spike 预训练。
2025.9
Qwen3-Next 与 GLM-4.6[19][23]
Qwen3-Next-80B-A3B 引入混合注意力 + 高稀疏 MoE + MTP；智谱 GLM-4.6（355B/32B）开源，200K 上下文。
2025.10
MiniMax-M2：极致稀疏 MoE[25]
230B 总参数仅激活 10B（稀疏率约 4.3%），登顶 Hugging Face 热榜，开源。
2026.2
GLM-5 开源[20]
智谱将 MoE 规模从 355B/32B 扩至 744B/40B，MIT 协议开源；同日 OpenAI GPT-5 系列已迭代至 5.2（2025.12）。
2026.2–4
Qwen3.5 与 Qwen3.6 开源[36][37]
Qwen3.5-397B-A17B（原生多模态 MoE，397B/17B，2 月）；Qwen3.6-35B-A3B（稀疏 MoE，35B/3B，4 月，主打 Agentic Coding）。
2026.4
DeepSeek V4 发布[39][40][41]
V4-Pro 1.6T 总/49B 激活、V4-Flash 284B/13B；官方仅公布规模，FFN/专家细节未披露。
2026.7
Kimi K3：896 专家的超大 MoE[21]
2.8T 总/104B 激活；896 路由专家激活 16 + 2 共享专家，配自研 Kimi Delta Attention 混合线性注意力。
2026.8–9
Qwen3.8-Flash 与 DeepSeek V4.1 Flash[18][24]
Qwen3.8-Flash（125B 激活 6B，含 51B n-gram embedding）；DeepSeek V4.1 Flash 采用非对称 Causal-Encoder-Decoder MoE（输入激活 8B/输出激活 16B）。

2.1 激活函数演进：ReLU → GELU → SiLU/Swish → GLU 家族 → SwiGLU

FFN 中间非线性函数的每一次更换，都等价于换了一种“token 特征再加工”的方式；趋势是从分段硬阈值走向平滑自门控。

起点：ReLU（2017）

原始 Transformer 的 FFN 为[1]：

FFN(x) = max(0, x·W₁ + b₁) · W₂ + b₂，　d_ff = 2048 = 4·d_model（base 版）

ReLU（Rectified Linear Unit）计算极便宜，但在负值区梯度恒为 0，存在“神经元死亡”风险，且函数在 0 点不可导。

GELU：引入随机正则化视角（2016 论文，2019 年进入 Transformer）

高斯误差线性单元（Gaussian Error Linear Unit, GELU）由 Hendrycks 与 Gimpel 于 2016 年提出[2]，定义为 GELU(x) = x · Φ(x)，其中 Φ(x) 是标准正态累积分布函数——直观含义是“按 x 属于正态分布的概率对 x 做随机门控”。GPT-2（2019）首次把 GELU 用于 Transformer[3]，此后 BERT、GPT-3 沿用。实现上有两种形式：精确形式用误差函数 0.5x(1+erf(x/√2))；工程上常用 tanh 近似 x·σ(1.702x) 以避免 erf 调用（GPT-2 时代代码中的 gelu_new 即此近似）。

SiLU / Swish：自门控激活（2017）

Swish（后在 PyTorch 中官方命名为 SiLU，Sigmoid Linear Unit）由 Google 于 2017 年提出[4]：

SiLU(x) = Swish(x) = x · σ(x) = x / (1 + e⁻ˣ)

因为门控系数 σ(x) 是输入 x 自己的函数，SiLU 被称为“自门控”（self-gated）激活。它处处平滑可导、非单调（负值区先降后升），在 ImageNet 上被验证优于 ReLU。

GLU 家族：把“门控”升级为显式第二路权重（2020）

Shazeer 2020 年的论文《GLU Variants Improve Transformer》系统对比了一族“门控线性单元”[5]：通用形式为两路线性投影逐元素相乘，一路做激活、一路做门控：

GLU 族：　y = g(x·W₁ + b₁) ⊙ (x·V + c)
GLU: g=σ；Bilinear: g=恒等；ReGLU: g=ReLU；GeGLU: g=GELU；SwiGLU: g=Swish

其中最有影响力的是 SwiGLU：SwiGLU(x) = Swish(x·W₁ + b₁) ⊙ (x·V + c)，最后再经 W₂ 投影回 d_model。相比标准两权重 FFN，它多出一路门控矩阵 V，参数量约为原来的 1.5 倍；论文与后续实践普遍把中间维 d_ff 从 4·d_model 下调到约 (2/3)·8·d_model 量级（如 Llama-7B 为 11000≈2.69·d_model）来补偿[5][34]。

Shazeer 的实验表明 GeGLU/SwiGLU 在同等训练步数下困惑度优于 ReLU 标准 FFN[5]。此后 PaLM（2022）[6]、Llama 系列（2023 起）[34]、Mistral、Qwen、Gemma 等主流开源模型几乎全部采用 SwiGLU（即 up/gate/down 三权重门控 FFN）；Gemma 2/3 则采用 GELU 的门控变体（GeGLU 类，配置中名为 gelu_pytorch_tanh）[14][35]。

2.2 结构演进：从两线性层到门控三权重，再到并行 FFN

同样是 SwiGLU，Llama 是“先注意力后 FFN 串行”，PaLM 之后越来越多模型把两者并到同一条残差分支上。

标准 FFN → 门控 FFN

标准 FFN 用 up_proj + down_proj 两个权重；门控 FFN（SwiGLU）拆为三个：gate_proj（SwiGLU 左支）与 up_proj 逐元素相乘后再经 down_proj 投影。代价是门控支路带来约 50% 的额外参数，换来的是更稳定的训练与更好的精度/参数比——这是 2023 年后稠密模型的事实标准[5][34]。

并行 FFN（Parallel Attention & FFN）

原始（及 Llama 式）Block 是 x → Attention(x) → FFN(·) 的串行两段残差。PaLM（2022）改为在同一残差分支上并行[6]：

y = x + Attention(LN(x)) + FFN(LN(x))　（PaLM 式并行）
y₁ = x + Attn(LN(x))；y = y₁ + FFN(LN(y₁))　（Llama 式串行）

并行结构把两段子层合并成一次“加和”，省一层 LayerNorm 的串行依赖，在 540B 规模上验证可行[6]；后续 PaLM 2、部分开源复现沿用该思路。

扩张比（d_ff/d_model）的实际取值

原始 Transformer 把 FFN 中间维定为 4·d_model[1]。引入 SwiGLU 三权重后，为控制总参数，各模型普遍把名义扩张比下调：Llama-7B 为 11000/4096≈2.69[34]，Mistral-7B 为 14336/4096=3.5，Qwen2-7B 为 11008/3584≈3.07（HF 配置口径[35]）。注意门控 FFN 的“等效计算量”仍接近旧 4× 结构。

Pre-Norm 框架下的层序

自 GPT-2/GPT-3 起主流采用 Pre-Norm（LN 在子层之前），FFN 与 attention 交替堆叠：每一层为一个 Block，Block 内 FFN 永远紧跟在该 Block 的注意力之后（或与之并行）；FFN 自身不改变位置编码、不做 token 间混合，是纯粹的逐 token 变换[1][3]。

2.3 MoE 化主线：FFN 复制为“专家”，按 token 稀疏激活

MoE（Mixture-of-Experts）把每个 Block 的 FFN 复制 N 份成为 N 个专家，路由器（router/gate）按 token 选择其中少数几个参与计算——总参数暴涨而每 token 算力近似不变。

从 GShard 到 Switch Transformer（2020–2021）

GShard（2020）首次在 600B 级模型上验证 Top-2 路由：每 token 经 softmax 门控选 2 个专家加权求和[7]。Switch Transformer（2021）把路由简化为 Top-1（只选分数最高的 1 个专家），训练 FLOPs 减半，模型扩至 1.6T，并提出辅助损失（auxiliary loss）鼓励专家负载均衡[8]。

Mixtral 8×7B：粗粒度专家 + Top-2（2023.12）

Mixtral 8×7B 把 Llama 式 FFN 整体复制 8 份作为专家，每 token 激活 Top-2 个，注意力层仍共享（不分专家）[9]。总参数约 46.7B、每 token 激活约 12.9B，是首个证明“开源 MoE 可达到稠密大模型水平”的爆款，确立了“大而少”的粗粒度专家路线。

DeepSeek-V2：细粒度专家 + 共享专家（2024.5）

DeepSeek-V2（236B 总/21B 激活）把专家切细：256 个路由专家、每 token 激活其中 6 个（Top-6），并另设 2 个共享专家（shared experts）对所有 token 恒定激活，承载通用知识，减少路由专家间冗余[10]。细粒度 + 共享专家由此成为后续国产旗舰的标准配方。

DeepSeek-V3：无辅助损失负载均衡（2024.12）

DeepSeek-V3（671B 总/37B 激活）沿用 256 路由专家 + Top-8，但把共享专家减为 1 个，并用可学习的路由 bias 做负载均衡，取消了 Switch 时代的辅助损失——避免辅助损失干扰专家专业化[11]。这一“无辅助损失负载均衡”被后续 Kimi K2、GLM-4.5/4.6 等广泛沿用[13][19]。

2025–2026：MoE 成为旗舰默认形态

2025 年起，新旗舰几乎清一色 MoE：Qwen3-235B-A22B（128 专家激活 8，取消共享专家，改用 global-batch 负载均衡损失）[12]；Llama 4 Maverick（128 专家、每 token 激活 2 个、专家 hidden 8192）[16][33]；Kimi K2（1.04T/32B，沿用 DeepSeek-V3 式架构）[13]；GLM-4.5/4.6（355B/32B）[19]；MiniMax-M2（230B/10B）[25]。进入 2026 年：GLM-5 扩至 744B/40B[20]；Kimi K3 把路由专家数推到 896（激活 16）+2 共享专家，总参数 2.8T/激活 104B[21]；DeepSeek V4 于 2026 年 4 月发布（V4-Pro 1.6T 总/49B 激活、V4-Flash 284B/13B，FFN/专家细节官方未披露）[39][40][41]；DeepSeek V4.1 Flash 更引入非对称 Causal-Encoder-Decoder 结构，输入侧激活 8B、输出侧激活 16B[18]；Qwen3.8-Flash 则在 MoE 之外叠加了 51B 的 n-gram embedding 查表参数[24]；阿里上半年还连续开源 Qwen3.5-397B-A17B（原生多模态 MoE，397B/17B）与 Qwen3.6-35B-A3B（稀疏 MoE，35B/3B）[36][37]。闭源侧，OpenAI GPT-5/5.1/5.2 官方称采用“统一系统 + 快速模型与深度推理模型之间的路由”，但未披露 FFN/专家细节[26][27][28]；Gemini 3 被第三方分析为 Sparse MoE，官方未披露细节[29]。

门控 FFN（SwiGLU）gate + up + down 三权重比标准多约 50% 参数；常用下调 d_ff 补偿100%无（固定）Llama、Mistral、Qwen 稠密版 [5][34]精度/参数比更好；参数仍全激活
并行 FFN同门控/标准 FFN，只是与 attention 同残差并行计算量不变；少一层串行 LN 依赖100%无（固定）PaLM、PaLM 2 [6]大模型下训练更省串行延迟；串行等价结构仍常见
粗粒度 MoE（专家大而少）N 个专家 FFN，共享注意力总参数≈N×专家，FLOPs≈激活专家数×专家约 27.6%（Mixtral 12.9/46.7）Top-2 路由 + 辅助损失均衡Mixtral 8×7B、GShard、Switch Top-1 [7][8][9]参数大、激活小；专家粗→通信/冗余问题
细粒度专家 + 共享专家M 个细粒度路由专家 + K 个恒定共享专家专家切细→负载更均；共享专家恒定激活DeepSeek-V3 约 5.5%（37/671）；Qwen3 约 9.4%（22/235）Top-k 路由；V3 用路由 bias 无辅助损失；Qwen3 用 global-batch 损失DeepSeek-V2/V3、Kimi K2/K3、GLM-4.5/4.6/5 [10][11][12][13][19][20][21]当前旗舰主流；显存占用=全专家，需专家并行

注：“每 token 激活参数占比”= 激活参数/总参数，MoE 中注意力与共享专家等恒定部分均计入；不同论文对“激活参数”口径略有差异（是否计入 embedding/共享专家），本表以官方公布口径为准并在正文标注。
