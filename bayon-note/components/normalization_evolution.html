总览

归一化（Normalization）回答一个问题：如何在网络层数不断加深时，让每一层输入的均值与方差保持稳定，使梯度不随深度指数放大或消失。2015 年的 BatchNorm 在 CNN 上大获成功，却与变长序列、自回归生成天然不兼容；2016 年的 LayerNorm 把统计从 batch 维移到特征维，成为 Transformer 的默认件；2019 年 RMSNorm 砍掉均值中心化只保留重缩放；2023 年起 QK-Norm 把归一化搬进注意力内部。

1.1 BatchNorm：从 batch 统计出发，却在序列任务中碰壁

批量归一化（Batch Normalization, BatchNorm）由 Ioffe 与 Szegedy 于 2015 年提出[1]：在训练时对每个神经元沿着批量与空间维度计算均值 μ 与方差 σ²，对激活做仿射归一化，并在推理时用滑动平均（running mean/variance）统计。它在 ImageNet 上把内部协变量偏移（internal covariate shift）压下来，允许更大学习率、加速收敛。

但 BatchNorm 在 Transformer / 序列任务中几乎不可用[2][3]，原因有三：其一，它依赖批量统计，变长序列与不等长 batch 无法共用同一组统计量；其二，自回归生成（decoding）时逐 token 产生，batch 内只有一条序列，统计量无意义；其三，训练时用 batch 统计、推理时用滑动统计，两套模式在动态序列长度下容易失配。因此 NLP 社区很快转向了"单样本、逐 token"的归一化。

1.2 LayerNorm：把统计搬到特征维，成为 Transformer 默认件

层归一化（Layer Normalization, LayerNorm）由 Ba、Kiros 与 Hinton 于 2016 年提出[2]：对每个 token 的特征向量整体计算均值与方差，再做仿射缩放 γ 与平移 β：

LayerNorm(x) = (x − μ) / √(σ² + ε) · γ + β

它与 batch 大小、序列长度完全解耦，天然适合 RNN 与 Transformer。2017 年原始 Transformer（Vaswani 等）在每个子层（自注意力、FFN）输出之后、残差相加之后做 LayerNorm，即 Post-LN（"Add & Norm"）[3]。Post-LN 在浅网络下没问题，但网络加深后训练极不稳定、必须依赖学习率预热（warmup）。

1.3 Pre-LN 主流化：把归一化挪到子层输入侧

2020 年 Microsoft Research 的 Xiong 等在《On Layer Normalization in the Transformer Architecture》中给出机理分析[5]：Pre-LN（把 LN 放在子层输入侧，残差通路直接走恒等映射）让反向梯度沿残差流无衰减地回传，初始化时梯度量级有界，可以去掉 warmup；而 Post-LN 的梯度方差随层数 N 指数振荡，深层难以收敛。后续信号传播理论工作进一步量化了这一差异：Pre-LN 反向梯度量级随深度按双曲线趋于 N，Post-LN 则指数放大或缩小[17]。

GPT-2（2019）与 GPT-3（2020）均采用 Pre-LN[6]，2023 年后几乎所有主流开源大模型（Llama、Mistral、Qwen、DeepSeek 等）都把"Pre-Norm + 归一化"作为默认配方[12]。

1.4 RMSNorm：砍掉均值中心化，只保留重缩放

2019 年 Zhang 与 Sennrich 提出均方根层归一化（RMS Normalization, RMSNorm）[4]：假设 re-centering（均值中心化）对训练帮助不大，只对向量的均方根（RMS）做归一化：

RMSNorm(x) = x / √(Mean(x²) + ε) · γ

论文在多种网络上实测：RMSNorm 与 LayerNorm 精度相当，运行时间在不同模型上减少 7% ∼ 64%[4]（注意：不是常见的"固定省 7%"说法，而是随模型与硬件从 7% 到 64% 不等的区间）。2023 年 Llama 1 起，RMSNorm 取代 LayerNorm 成为开源大模型事实标准[12]；FlashNorm 等后续工作进一步指出，对 270M 量级模型，RMSNorm 全部移除的吞吐上限也只有约 10%，说明其在大模型中开销已很小[22]。

1.5 深层稳定变体：DeepNorm、Sandwich-Norm、NormFormer

当网络向 100～1000 层扩展时，单靠 Pre-LN 仍不够：DeepNorm（Wang 等，2022，DeepNet）在 Post-LN 残差路上把恒等分支乘以常数 α、残差分支权重按 β 缩小，理论上把更新量界住，支撑训练到 1000 层[10]；Sandwich-Norm（前后都做归一化）最早见于 CogView 2021[9]，2024 年 Gemma 2 把"Pre-Norm + Post-Norm 各一层 RMSNorm"作为标配[20]；NormFormer（Shleifer 等，2021，FAIR）在 Pre-LN 基础上额外加三个轻量归一化，参数只增加 0.4%，相同算力下收敛更快[8]。

1.6 QK-Norm：把归一化搬进注意力内部

注意力 logits = QKᵀ/√d 是双线性形式，Q、K 权重的谱范数一涨，logits 就被平方放大，容易饱和 softmax。最早 Henry 等（2020）在低资源翻译上提出对 Q、K 沿 head 维做 ℓ2 归一化[7]；2023 年 Google 的 ViT-22B 用 LayerNorm 归一化 Q、K 后才稳定训练[11]；2024 年 Gemma 3 用 per-head RMSNorm（QK-Norm）替换掉 Gemma 2 的 soft-capping[26]；2025 年 Qwen3 明确引入 QK-Norm 保证训练稳定[25]，Llama 4 Scout 也在 RoPE 之后对 Q、K 做无可学习参数的 RMSNorm[31]。

演进时间线

归一化主线：BatchNorm（2015）→ LayerNorm（2016）→ Pre-LN 主流化（2019-2020）→ RMSNorm（2019，2023 年起事实标准）→ 深层稳定变体（2021-2022）→ QK-Norm 进入注意力（2023-2026）。

2015
BatchNorm 提出[1]
Ioffe & Szegedy：沿 batch 维统计均值/方差，加速 CNN 收敛。
2016
LayerNorm 提出[2]
Ba, Kiros, Hinton：沿特征维逐 token 归一化，摆脱 batch 依赖。
2017
原始 Transformer 采用 Post-LN[3]
Vaswani 等：每个子层输出后做 LayerNorm（"Add & Norm"）。
2019
RMSNorm 提出[4]；GPT-2 采用 Pre-LN[6]
砍掉均值中心化；论文实测运行时间减少 7%∼64%。
2020
Pre-LN 理论定型[5]；QK-Norm 首次提出[7]；GPT-3 沿用 Pre-LN[6]
Pre-LN 梯度有界、去 warmup；Henry 等对 Q/K 做 ℓ2 归一化。
2021
NormFormer[8]；Sandwich-LN 见于 CogView[9]
额外轻量归一化，参数 +0.4%、收敛更快；前后都归一化。
2022
DeepNet / DeepNorm[10]
残差缩放 α、分支权重缩放 β，理论上训练到 1000 层。
2023
ViT-22B 普及 QK-LN[11]；Llama 1 让 RMSNorm 成为事实标准[12]
Dehghani 等用 LayerNorm 归一化 Q/K；Llama 起开源模型普遍 RMSNorm+Pre-Norm。
2024
Gemma 2 采用 Sandwich-RMSNorm[20]；DeepSeek-V3 用 RMSNorm 并在 MLA 压缩潜向量后追加归一化[23]
Gemma 2 注意力 soft-cap 50；DeepSeek-V3 训练全程无 loss spike。
2025
Gemma 3 用 QK-Norm 替换 soft-cap[26]；Qwen3 引入 QK-Norm[25]；Llama 4 Scout 在 RoPE 后归一化 Q/K[31]；Kimi K2 用 QK-Clip 替代 QK-Norm[27]；DeepSeek-V3.2 沿用 V3 归一化、仅换 DSA[28]；Qwen3-Next 改用 Zero-Centered RMSNorm[29]
QK-Norm 成为 2025 年开源旗舰的新标配；不同厂商对"如何稳住 Q/K"开始分叉。
2026
"Post-LN Is Back" 引发后归一化回潮讨论[33]；Qwen3.5 混合 GDN+MoE、GLM-5 引入 DSA[30]；DeepSeek V4（2026-04）仅披露 CSA+HCA 混合注意力、归一化未公开[37]
学界重新评估 Post-LN 表达力；归一化在混合架构中的角色仍在演进，2026 年多数新模型细节未公开。

方法对比表

覆盖 7 种归一化方案，从公式、提出时间、梯度/稳定性/开销影响、代表模型 5 个维度对比。

方法公式（简）提出时间/论文对梯度 / 稳定性 / 开销的影响代表模型
BatchNorm y = γ·(x−μ_batch)/√σ²_batch + β，μ/σ 沿 batch×空间维统计 2015，arXiv:1502.03167[1] CNN 上收敛快；但依赖 batch 统计，变长序列 / 自回归推理不兼容，训练-推理两套统计 ResNet 系列（视觉）；未用于主流 LLM
LayerNorm (x−μ)/√(σ²+ε)·γ + β，μ/σ 沿特征维逐 token 2016，arXiv:1607.06450[2]；Transformer Post-LN 2017[3] 与 batch 无关；Post-LN 梯度方差随深度指数振荡、需 warmup；归一化本身要算均值+方差两次 原始 Transformer、BERT、GPT-2/3、Phi-2/4、Falcon-180B
Pre-LN（结构变化） x + Sublayer(LN(x))，LN 在子层输入侧 2019 GPT-2 采用；2020 理论定型 arXiv:2002.04745[5] 残差流恒等直连，反向梯度量级初始化有界、可去掉 warmup；代价是深层表达力略降 GPT-2/3、PaLM、几乎所有 2023+ 开源 LLM
RMSNorm x/√(Mean(x²)+ε)·γ，去掉均值中心化与 β 2019，arXiv:1910.07467[4] 与 LayerNorm 精度相当，运行时间实测减少 7%∼64%；270M 小模型移除全部 RMSNorm 吞吐上限仅约 +10%[22] Llama 1/2/3、Mistral/Mixtral、Qwen2/2.5、DeepSeek-V2/V3、GLM-4.5、InternLM2/3、Yi、Baichuan2
DeepNorm xₗ₊₁ = LN(α·xₗ + Gₗ(xₗ))，分支权重按 β 缩小 2022，arXiv:2203.00555（DeepNet）[10] 结合 Post-LN 表达力与 Pre-LN 稳定性，理论上界住更新量，训练到 1000 层 DeepSeek-V2（α=1.5 残差缩放）[19]
Sandwich-Norm 每个子层前后各做一次归一化：LN_in(x) 与 LN_out(x + Sublayer(·)) 2021 见于 CogView[9]；2024 Gemma 2 推广 前稳梯度、后稳幅度，深层训练抖动更小；开销约多一倍归一化算子 Gemma 2 / Gemma 3（pre_+post_attention_layernorm）[20][26]
NormFormer Pre-LN 基础上：注意力后加 LN + head-wise 缩放 + FFN 第一线性层后加 LN 2021，arXiv:2110.09456（FAIR）[8] 参数仅 +0.4%，相同算力下 1.3B 模型收敛到同等困惑度快 24% FAIR 实验模型；未成为单一开源旗舰标配
QK-Norm softmax(LN(Q)·LN(K)ᵀ/√d)·V（或 per-head RMSNorm），只归一 Q/K，V 不归一 2020 arXiv:2010.04245（Henry 等 ℓ2 版）[7]；2023 ViT-22B 普及 LayerNorm 版[11] 把 Q/K 每 head 的 RMS 压到约 γ，抑制注意力 logits 平方放大，避免 softmax 饱和；开销极小 ViT-22B、Gemma 3、Qwen3、Llama 4 Scout（post-RoPE、无可学习参数）[25][26][31]
