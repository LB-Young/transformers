总览与技术脉络

自注意力本身对位置是“盲”的：打乱 token 顺序不会改变逐对注意力分数。位置编码（Positional Encoding, PE）就是把“第几个 token”这一信息以某种方式注入模型的设计。2017–2026 年，这条线从固定正弦函数、可学习绝对向量，一路演进到旋转位置编码（Rotary Position Embedding, RoPE）主导、再到部分旋转（Partial RoPE）、层间交替免位置（iRoPE / NoPE）与多维（2D / M-RoPE）编码。

理解位置编码的演进，抓住两条主线即可。第一条是“显式编码 → 相对编码 → 隐式/乘法式编码”：早期方案把位置作为一个额外向量加在输入上（绝对式），随后 T5、Transformer-XL 把相对距离做成注意力分数上的偏置（相对式），RoPE 则不再加任何向量，而是用旋转矩阵把位置揉进 Query/Key 的内积里——位置信息只以“相对角度差”的形式隐式存在。第二条是“训练长度 → 推理长度”的外推战争：固定训练上下文之后，如何不靠重训（或少重训）把可用上下文从 4K、8K 拉到 128K、1M 甚至 10M，催生了位置插值（Position Interpolation, PI）、NTK-aware、YaRN、LongRoPE 等一整套 RoPE 重缩放技术，也直接决定了每个主流模型的 θ（基频）取值。

1.1 绝对式：Sinusoidal（2017）与 Learned Absolute（2018）

原始 Transformer（“Attention Is All You Need”, 2017）使用固定正弦位置编码：对位置 pos 与维度 i，用不同频率的 sin/cos 生成向量并直接加到 token embedding 上[1]。它无需训练参数，但表达能力有限，且对超出训练长度的序列没有自然外推能力。

PE(pos, 2i) = sin(pos / 10000^(2i/d))　　PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

同一时期的 GPT-1（2018）与 BERT（2018）[2][3] 改用可学习绝对位置嵌入（Learned Absolute Positional Embedding）：为每个位置分配一个可训练向量，从 0 编到最大序列长度。BERT 最大位置 512，GPT-1/2 为 1024。这种方案简单有效，但“序列一长就得从头扩位置表”，是 2019 年后相对式与旋转式兴起的直接动因。已查证

1.2 相对式：Transformer-XL、T5 Relative Bias、DeBERTa

Transformer-XL（2019, arXiv:1901.02860）[4] 做了两件影响深远的事：一是段级状态复用（segment-level recurrence），把上一段隐状态缓存下来作为下一段的上下文；二是把绝对位置向量换成相对位置编码，注意力分数中显式使用 i 与 j 的相对距离。它把 RNN 式的长程记忆嫁接到 Transformer 上，但相对位置仍以加性项存在。

T5 Relative Bias（2019/2020, arXiv:1910.10683）[5] 把“相对距离”做成注意力 logits 上的可学习偏置，并用桶化（bucketed）压缩距离空间：对小于某个阈值的近距离用精确桶、对远距离用对数间隔桶，T5 官方实现使用 32 个桶。桶化是把“无限远的距离”压成有限参数表的经典工程折中。

DeBERTa（2021, arXiv:2006.03654）[6] 更进一步提出解耦注意力（Disentangled Attention）：把注意力拆成内容对内容、内容对位置、位置对内容三部分，位置与内容不再捆绑在同一个向量里。它证明“位置信息可以从内容向量里拆出来单独算”，这一思想在 2024 年后的部分旋转设计中以另一种形式回潮。

1.3 免参数外推：ALiBi（2022）

ALiBi（Attention with Linear Biases, 2022, arXiv:2108.12409）[7] 干脆不加任何位置向量：注意力分数在 softmax 之前直接减去一个与距离成正比的惩罚项，每个注意力头有一个固定斜率 m（按 2^(-8/n_heads) 几何取），惩罚项为 -m · |i - j|。优点是零参数、零额外存储，且对超出训练长度的序列有自然外推能力——它当年在 BLOOM（2022）上以 1024 训练长度外推到 2048 以上[8]。Falcon-7B/40B/180B 也采用了 ALiBi[9]。ALiBi 的局限是：线性惩罚对“远距离该注意什么”表达力弱，且实测其下游长任务外推并不优于显式相对位置（NoPE 论文中 ALiBi、RoPE、APE 三者长度泛化均不佳）[10]。

1.4 RoPE（2021）及其统治地位

RoPE（Rotary Position Embedding, 2021, arXiv:2104.09864）[11] 不向 embedding 加位置向量，而是对 Query 和 Key 在每一层做复数旋转：把每两个维度视为一个复数，按位置 pos 与维度频率 θ_i = 10000^(-2i/d) 旋转角度 pos · θ_i。旋转后 q_i · k_j 的内积只依赖 i 与 j 的相对差，因而天然携带相对位置信息。高频维度（小 θ）编码近距离细节，低频维度（大 θ，即序列末端）编码长程依赖——这一“频段分工”正是后来所有外扩技术的操作对象。

f(x_m, m) = (R_m ⊗ W_q)x_m · (R_n ⊗ W_k)x_n ⇒ q_m^T k_n = g(x_m, x_n, m - n)

自 Llama 1/2（2023）将 RoPE 作为默认实现[12]后，它迅速统治开源圈：Llama 3/3.1、Qwen2/2.5/3、Mistral、Yi、Baichuan2-7B、GLM-4.5、Phi-3/4、Gemma 2/3、Kimi K2、DeepSeek-V3 等均采用 RoPE 家族方案[13][14][15][16]。可以说 2023 年后的“位置编码”几乎等价于“RoPE 及其重缩放变体”。

1.5 上下文外扩：PI、NTK、YaRN、LongRoPE 与官方扩展

RoPE 的旋转角度与位置成正比，训练长度之外角度“卷过头”，性能崩塌。社区与学术界为此发展出一整套重缩放技术：

位置插值 PI（2023, arXiv:2306.15595）[17] 直接把位置坐标线性压缩 s 倍（s = 目标长度/训练长度），让 8K 位置映射回 4K 的刻度；问题是近距离分辨率被等比例牺牲。NTK-aware（2023 年 6 月，Reddit r/LocalLLaMA 用户 bloc97 提出）[18] 不压缩坐标，而是按 NTK 理论只抬升基频 θ：高频维度基本不动、只重排低频维度，从而保住近距离精度；其推理时按实际序列长度动态调整倍率的版本称为 Dynamic NTK（emozilla, 2023）[19]；把高频段完全不缩放、只对低频段按线性插值缩放的折中称为 Part NTK / 部分线性缩放。

YaRN（2023, arXiv:2309.00071, ICLR 2024）[20] 系统化上述思路：分频段分别处理高频（保留）、中频（截断）、低频（外推），并用温度修正补偿注意力分布，比此前方法少用 10 倍 token、少 2.5 倍训练步即可完成上下文扩展，Llama 系列被 YaRN 微调后可外推至 128K。LongRoPE（2024, arXiv:2402.13753）[21] 则按维度搜索非均匀的重缩放因子，Phi-3 用它把 4K 扩到 128K[22]。厂商侧的“官方扩展”也多是这套组合拳：Llama 3.1 对 405B 继续预训练把上下文从 8K 提到 128K[13]；Qwen3 在 32K 原生长度基础上用 YaRN + Dual Chunk Attention 再扩 4 倍到 128K[14]；Kimi K2 用 YaRN 把 4K 训练段推到 128K[15]。

1.6 NoPE 的发现与“Llama-3 仅少数层使用 RoPE”的核验

NoPE（No Positional Encoding）最有代表性的实证研究是 Kazemnejad 等人的 NeurIPS 2023 论文[10]：他们在合成任务上系统比较 APE、T5 Relative Bias、ALiBi、RoPE 与完全无位置编码的解码器，发现 NoPE 的长度泛化反而优于所有显式 PE——因果掩码本身（位置 i 看不到 j>i）就打破了 token 顺序的对称性，模型能从“谁能看到谁”反推出顺序。需要澄清：任务书中提到的 arXiv:2410.01131 经联网核验并不是 NoPE 论文，而是 nGPT（归一化 Transformer）论文[23]，此处予以更正。

关于网传说法“Llama-3 仅首层（或少数层）使用 RoPE”，本次核验结论为：未核实。Meta 官方 Llama 3 技术报告与公开实现（HF transformers、模型 config）均为全部注意力层统一应用 RoPE（θ=500000），没有“只有首层加位置”的设计[13]。该说法更可能是对两类后续工作的误读：其一，机制分析论文发现 RoPE 的角度对齐信号在浅层（通常前几层）最强、深层衰减[24]；其二，2025 年后的真实设计确实走向了“部分层/部分维度免旋转”——Llama 4 的 iRoPE 让 48 层中每第 4 层（共 12 层）不使用旋转[25]，Qwen3-Next 只对前 25% 位置维度施加旋转[26]，GLM-4.5、Phi-4-mini 采用部分旋转（25% 维度保持与位置无关）[16][27]。Kimi Linear（2025）更进一步，在全部 MLA 全注意力层上使用 NoPE，把位置与近因偏差完全交给 KDA 线性层承担[28]。即：“Llama-3 本体只有少数层用 RoPE”没有官方依据，但“2025–2026 的新架构确实在系统性减少 RoPE 作用范围”是已查证事实。

1.7 多模态：2D 位置编码

图像是二维结构，一维位置编码无法表达“同行相邻 patch”与“隔列远 patch”的差别。ViT（2020, arXiv:2010.11929）[29] 对 patch 使用可学习 2D 绝对位置嵌入（或等价的 2D 正弦）。Qwen2-VL（2024, arXiv:2409.12191）[30] 把 ViT 的绝对位置嵌入移除，引入 2D-RoPE（M-RoPE）：把旋转角度拆成高度、宽度两个分量，让视觉 token 的相对位置沿两个轴分别编码，并把该方案保留给语言侧注意力（文本 token 只走 1D 角度）；Qwen3-VL 进一步用 Interleaved-MRoPE 把时间、宽、高三个维度交错分配频率[31]。GLM-4.5V 的 ViT 同样集成了 2D-RoPE 以支持极端宽高比与超分图像[32]。这一路线本质是 RoPE“按维度分配旋转频率”思想从 1D 序列向 2D/3D 时空的自然推广。
