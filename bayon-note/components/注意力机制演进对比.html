§1 演进时间线（2017 → 2026）

十二个里程碑串起一条主线：先把 O(n²) 的数学复杂度往下压（稀疏化、线性化、状态空间化），再把 GPU 内存层级 IO 压榨到极致（FlashAttention 系），最后把 KV Cache 压缩与动态稀疏组合起来（MLA、NSA/MoBA、DSA、混合架构）。每个节点附论文 / 官方出处。

2017

Softmax Attention 基线：Transformer 【已查证】

Vaswani et al.（Google Brain）提出全注意力 + 多头机制，彻底抛弃 RNN/CNN。注意力分数矩阵 O(n²·d)，训练 / 推理同阶，KV 随序列长度线性膨胀且无法压缩——这是之后所有工作要突破的瓶颈。

论文：Attention Is All You Need, arXiv:1706.03762

2019

MQA：Multi-Query Attention 【已查证】

Noam Shazeer（Google）指出自回归解码是 memory-bound，KV 张量带宽才是瓶颈。h 个 query 头共享同一份 K/V，注意力 FLOPs 不变，但 KV Cache 与解码读 KV 的内存带宽降为 1/h，质量仅轻微下降。

论文：Fast Transformer Decoding: One Write-Head is All You Need, arXiv:1911.02150

2019–2020

稀疏注意力家族：Sparse Transformer / Longformer / BigBird 【已查证】

第一次把 O(n²) 拉到近线性：Sparse Transformer 用局部 + 空洞 factorized 模式（O(n·√n)）；Longformer 用滑窗 O(n·w) + 少量全局 token；BigBird 再加随机 token，证明稀疏注意力仍是通用逼近器。滑窗 SWA 作为公共组件被 Mistral 7B 等发扬光大。代价是静态稀疏、需定制 kernel，未成为 decoder LLM 主干。

出处：Sparse Transformer 1904.10509 ｜ Longformer 2004.05150 ｜ BigBird 2007.14062

2020

线性 / 核近似注意力：Linear Transformer / Performer 【已查证】

用核特征 φ(q)·φ(k) 代替 softmax，借助矩阵结合律把 O(n²) 降到 O(n)，自回归时可写成 RNN 形式（论文称超长序列推理快达 4000×）。Performer 用 FAVOR+ 随机特征无偏估计 softmax 矩阵。短板是精确检索 / 逐 token 召回弱，2022–2024 年间未进入主流 LLM。

出处：Linear Transformer 2006.16236 ｜ Performer 2009.14794

2022–2023

IO 感知内核：FlashAttention 1/2 + PagedAttention 【已查证】

Dao et al. 指出瓶颈在 HBM↔SRAM 的 IO 读写而非 FLOPs：tiling + online softmax 精确计算，不把 n×n 中间矩阵写回 HBM；FA2 改进并行划分达 50–70% MFU。同期 PagedAttention 借鉴 OS 虚拟内存分页，把 KV Cache 按块非连续存储、近零碎片，催生 vLLM 生态。二者不改变注意力 FLOPs 复杂度。

出处：FA1 2205.14135 ｜ FA2 2307.08691 ｜ PagedAttention 2309.06180（SOSP 2023）

2023

GQA：Grouped-Query Attention 【已查证】

Ainslie et al.（Google）在 MHA（h 个 KV 头）与 MQA（1 个 KV 头）之间取中间档：G 个 KV 头、每组 query 共享一份 K/V，且可从已训练 MHA checkpoint 直接转换、几乎无质量损失。自 Llama 2 70B 起成为主流，Llama 3、Mistral、Qwen、GLM 4.5/4.6 普遍采用。

论文：GQA, arXiv:2305.13245

2023

状态空间新范式：RetNet / RWKV / Mamba 【已查证】

第一次让 sub-quadratic 架构在语言建模上逼近 Transformer 质量：RetNet 兼得训练并行 + 推理 O(1) + 好性能；RWKV 用 RNN 形式重写 Transformer；Mamba 用选择性 SSM（参数随输入变化）实现线性时间、约 5× 推理吞吐，论文称可扩展到约 1M 序列。Mamba-2（2024）进一步用 SSD 框架把 SSM 与线性注意力统一。

出处：RetNet 2307.08621 ｜ RWKV 2305.13048 ｜ Mamba 2312.00752

2024

MLA：Multi-head Latent Attention（DeepSeek-V2）【已查证】

把 K/V 先联合下投影成低秩潜向量 c_KV（约 512 维），推理时只缓存 c_KV、再上投影恢复多头 K。注意力 FLOPs 仍为 O(n²·d)，但论文称 KV Cache 相比 67B 级模型降低约 93.3%、训练成本省 42.5%。被 DeepSeek-V3 / R1 / V3.1 沿用，Kimi K2 采用同构 MLA。

论文：DeepSeek-V2, arXiv:2405.04434

2024

差分注意力 Differential Transformer 【已查证】

把 Q/K 分两组算两个 softmax 注意力图再相减，类似差分放大器消除注意力共模噪声。复杂度与标准 softmax 同阶 O(n²·d)（约 2× 计算量），可直接复用 FlashAttention 内核；在长上下文关键信息检索、幻觉抑制上有收益。属于「改结构不改复杂度」的正交改进。

论文：Differential Transformer, arXiv:2410.05258

2025

原生动态稀疏：NSA / MoBA 【已查证】

NSA（DeepSeek）三分支——粗粒度 token 压缩 + 细粒度 top-k 块选择 + 滑窗——输出拼接，64K 长度上 decode/forward/backward 全程加速且不掉点。MoBA（Moonshot & 清华）把 MoE 思想搬到注意力：K/V 切块、按 query 路由选 top-k 块，可在全注意力与稀疏间无缝切换，已部署支撑 Kimi 长文本服务【一方称 / 未公开细节】。

出处：NSA 2502.11089 ｜ MoBA 2502.13189

2024–2026

混合注意力（Hybrid）：交错式 / 并行拼接式 【已查证】

两类组织方式必须区分：层间交错（layer-wise）——Gemma 3（5:1 滑窗:全局）、Llama 4 iRoPE（全局:分块局部 = 1:3）、Qwen3-Next（GDN 线性:全注意力 = 3:1）、Hunyuan-TurboS（Mamba2+Attn）；同层并行拼接（parallel）——Falcon-H1 同一 block 内注意力头与 Mamba-2 头并行输出拼接。兼顾线性效率与全注意力精确检索。

出处：Gemma 3 2503.19786 ｜ Llama 4 iRoPE（vLLM） ｜ Falcon-H1 2507.22448 ｜ Hunyuan-TurboS 2505.15431

2026

最新进展：FA4 / DSA / GLM-5 / Kimi K3 【已查证】

FlashAttention-4 针对 Blackwell B200 做算法 + kernel 流水线协同，BF16 达 1605 TFLOPs/s（71% 利用率）；DeepSeek-V3.2 引入 DSA（lightning indexer + 逐 query 动态 top-k 细粒度块）；GLM-5 摘要原文采用 DSA；Kimi K3（2.8T）用 KDA（Kimi Delta Attention）门控线性注意力 + 周期性全局 Gated MLA with NoPE，原生 100 万 token。

出处：FA4 2603.05451 ｜ DSA（DeepSeek-V3.2）2512.02556 ｜ GLM-5 2602.15763 ｜ Kimi K3

§4 FlashAttention 逐版对比（FA1 → FA4）

所有 FA 版本都是精确注意力（非近似），不改数学复杂度，优化的是 GPU 内存层级 IO；FP8/FP4 低精度为可选加速路径。

§5 关键机制速览

九个高频出现的机制，每个 1–3 句 + 出处。

MQA 多查询注意力

所有 query 头共享同一份 K/V；FLOPs 不变，KV Cache 与解码带宽降为 1/h，质量损失略大于 GQA。

出处：arXiv:1911.02150（PaLM、Falcon-7B 采用）

GQA 分组查询注意力

MHA 与 MQA 的中间档：G 个 KV 头、每组 query 共享一份 K/V；可从 MHA checkpoint 近乎无损转换，是 2023 年后开源模型事实标准。

出处：arXiv:2305.13245（Llama 3、Mistral、Qwen、GLM-4.5）

MLA 多头潜在注意力

K/V 联合下投影为低秩潜向量 c_KV（约 512 维），推理只缓存 c_KV、再上投影恢复多头 K；KV Cache 降约 93.3% 且保留多头表达，Q/K 拆解耦 RoPE。

出处：arXiv:2405.04434（DeepSeek-V2/V3/R1、Kimi K2）

NSA 原生稀疏注意力

三分支拼接：粗粒度 token 压缩（compress）+ 细粒度 top-k 块选择（select）+ 滑窗（sliding）；硬件对齐、端到端可训练，64K 全程加速不掉点。

出处：arXiv:2502.11089（DeepSeek）

MoBA 块级混合注意力

把 MoE 思想搬到注意力：K/V 序列切块，学习门控为每个 query 只选少数相关块；可在全注意力与稀疏间无缝切换，已部署支撑 Kimi 长文本【一方称】。

出处：arXiv:2502.13189（Moonshot & 清华）

GDN 门控线性递归

Gated DeltaNet（线性注意力）：在 DeltaNet 基础上加门控，维护固定大小循环状态、推理 O(1)；Qwen3-Next 起以 GDN:全注意力 = 3:1 层混合，Qwen3.5 中 GDN 约占 75%。

出处：arXiv:2412.06464；Qwen3-Next（vLLM）

KDA Kimi Delta Attention

在 Gated DeltaNet 上做更细粒度门控的线性注意力模块；官方称首次在公平对比下短 / 长上下文与 RL 扩展均超过全注意力。Kimi K3 进一步用 KDA + Attention Residuals + 周期性全局 Gated MLA with NoPE。

出处：arXiv:2510.26692；Kimi K3

iRoPE 交错位置编码

Llama 4 架构：全局注意力（不带 RoPE）与分块局部注意力（带 RoPE、chunk=8192、非重叠）按 1:3 层交替；把二次复杂度压到近线性，Scout 支持 10M、Maverick 1M。

出处：vLLM Llama 4 技术解读；HF 模型卡

DSA 深度稀疏注意力
