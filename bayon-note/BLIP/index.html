BLIP 家族架构详解

研读对象 models/blip/（transformers 5.23.0.dev0，本页所有行号/字段以此为准）。BLIP 是 Salesforce 提出的统一视觉语言框架：同一套 MED 文本参数以三种模式同时支持图文检索、图像描述、VQA，并用 CapFilt 从噪声网络图文对中引导出高质量训练集。与 CLIP 只做「对齐/匹配」不同，BLIP 理解与生成通吃——这是它最大的定位差异。

1一句话定位

BLIP（Bootstrapping Language-Image Pre-training，ICML 2022）是 Salesforce 的统一多模态框架（论文 arXiv:2201.12086）：同一套参数（MED，Multimodal mixture of Encoder-Decoder）以三种模式同时支持图文检索、图像描述生成、VQA，并用 CapFilt 机制从噪声网络图文对中「引导（Bootstrapping）」出高质量训练数据。它是 BLIP-2、InstructBLIP 的前身。

4端到端架构总览

图像 → 视觉塔（ViT，384×384 / patch 16 → 577 token）→ [CLS] 池化 + post_layernorm → 512 维视觉嵌入；文本 → 文本塔（12L/768/8H，is_decoder 可切换）→ 512 维文本嵌入。两塔在 BlipModel 层投影对齐，ITC/ITM/ITG 三头复用同一套特征。

跨注意力（ITM/ITG）路径：图像特征作为 encoder_hidden_states 注入文本塔，未在图中画出全部连线（见 §5）。

5MED：同一套文本参数，三种模式

BlipTextLayer（:272）在 is_decoder=True 时加入 cross-attention（:280-282），由此同一套 Transformer 权重可切换为三种模式：

模式使用目标实现
单模态编码器ITC（对比）BlipModel 中 text_model(input_ids)，无跨注意力
图像引导编码器ITM / VQAtext_model(..., encoder_hidden_states=image_embeds)，启用跨注意力
图像引导解码器ITG（生成）text_decoder(..., encoder_hidden_states=image_embeds, labels)，自回归 LM

6三个预训练目标

6.1 ITC 图文对比（BlipModel :509，代码 :730-744）

image_embeds = visual_projection(pooler_output)   # 768 → 512
text_embeds  = text_projection(pooler_output)     # 768 → 512
两者 L2 归一化 → 余弦相似度矩阵 × logit_scale   # 同 CLIP 对比逻辑

6.2 ITM 图文匹配（BlipModel / BlipForImageTextRetrieval :1165）

文本编码器以 image_embeds 为 encoder_hidden_states 做跨注意力融合；融合输出过 image_text_hidden_size=256 的二分类头，判断「图文是否配对」——与 ITC 的全局余弦对齐不同，ITM 是细粒度 token 级匹配。

6.3 ITG 图像引导文本生成（BlipForConditionalGeneration :769）

text_decoder 以 image_embeds 为跨注意力输入，自回归生成 caption，优化标准 LM loss；VQA（BlipForQuestionAnswering :942）同构，把问题也作为输入 token。

7训练方法：CapFilt（论文层面）

问题：网络图文对（如 LAION）噪声大，直接预训练会被错误文本带偏；人工标注质量高但量小。CapFilt 用「生成器 + 过滤器」两级引导：

训练数据来源：COCO / Visual Genome / Conceptual Captions / SBU Captions 等 14M 级人工标注数据 + 大规模网络图片（论文整体扩充规模约 1.29 亿张，具体构成以论文为准，待确认）。

一分钟结论

维度要点
架构ViT 视觉塔（12L/768/12H）+ 文本 Transformer（12L/768/8H，is_decoder 可切换）
MED同一套文本参数 = 单模态编码 / 图文编码（+跨注意力）/ 图文解码
三目标ITC 图文对比（512 维）· ITM 图文匹配（256 维融合头）· ITG 图像引导生成（LM）
数据CapFilt：Captioner 生成 + Filter 过滤，引导高质量训练集
池化视觉取 [CLS] + post_layernorm
代码入口BlipModel（检索/表示）· BlipForConditionalGeneration（字幕）· BlipForQuestionAnswering（VQA）· BlipForImageTextRetrieval（检索）
