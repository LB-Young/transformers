2端到端数据流总览

文本 token 经 Embedding（151936 × d_model，小尺寸与 LM Head 共享权重）→ N 个 DecoderLayer（pre-norm RMSNorm → GQA 注意力 → 残差；再 RMSNorm → SwiGLU → 残差）→ 最终 RMSNorm → LM Head。2-VL 另起一路：图像经 ViT（patch 14）编码、spatial merge 2×2 压成 image tokens，填入序列中 image_token（151655）位，统一走 M-RoPE 三维位置。悬停节点看细节。

全家族统一主干：Embedding → DecoderLayer×N → 最终 RMSNorm → LM Head；差异集中在层数、维度、KV 头数、滑窗窗口，以及是否挂 ViT 视觉塔（2-VL）或 MoE 路由（57B-A14B）。

3解码层解剖：pre-norm RMSNorm 残差块

Qwen2 的每个解码层（Qwen2DecoderLayer，modeling_qwen2.py:250-290）含两组残差子层：注意力与 FFN，均为 pre-norm（先 RMSNorm 再子层，结果与残差相加）。五尺寸共享此结构，仅维度随尺寸缩放。

Qwen2DecoderLayer.forward（modeling_qwen2.py:261-290）: residual = hidden_states hidden_states = input_layernorm(hidden_states) hidden_states, _ = self_attn(hidden_states, position_embeddings, ...) hidden_states = residual + hidden_states # ⊕1 residual = hidden_states hidden_states = post_attention_layernorm(hidden_states) hidden_states = self.mlp(hidden_states) # SwiGLU hidden_states = residual + hidden_states # ⊕2 return hidden_states

4核心机制：GQA · 滑窗注意力 · SwiGLU · RoPE · MoE

① GQA 分组与 repeat_kv

Qwen2 注意力把 Q 头数按 KV 头数分组，运行时 repeat_kv 把 K/V 从 KV 头复制到 Q 头数再做缩放点积注意力[S:130-140]。

Attn(Q,K,V) = softmax( QKᵀ / √d_k + mask ) V # 0.5B: 14Q / 2KV → repeat 7:1 # 72B: 64Q / 8KV → repeat 8:1 scaling = head_dim ** -0.5 # :178
分组比：0.5B 7:1、1.5B 6:1、7B/57B-A14B 7:1、72B 8:1。

② 滑窗注意力（layer_types 分层）

v5 的 Qwen2Config.__post_init__ 按层索引生成 layer_types：当 sliding_window is not None 且 i >= max_window_layers 时为 sliding_attention[CFG:88-94]。

layer_types = ["sliding_attention" if (sliding_window is not None and i >= max_window_layers) else "full_attention" for i in range(num_hidden_layers)] # Qwen2-0.5B: 24 层, max_window_layers=24 # Qwen2-7B: 28 层, max_window_layers=28, 窗 131072
踩坑：本机与官方 config 均 use_sliding_window=false → v5 全层 full_attention，SWA 机制保留在源码中。

③ RMSNorm 与 SwiGLU

RMSNorm 先 fp32 归一，再乘可学习权重 γ[S:230-247]。FFN 为三投影门控 SwiGLU（silu 激活）[S:34-48]。

rms(x) = sqrt( mean(x²) + eps ) y = γ · x / rms(x) FFN(x) = down( silu(gate(x)) ⊙ up(x) )
hidden_act=silu；eps=1e-6。

④ RoPE（θ=1e6）

旋转位置编码基频 rope_theta=1000000.0（本地 config）[S:50]。逆频率对 Q/K 前若干维旋转。

inv_freq_i = base ^ (-2i / head_dim), base=1e6 q_rot = q·cos θ + rotate_half(q)·sin θ # 2-VL 另用 M-RoPE（见 §6）

⑤ MoE（57B-A14B）

Qwen2 首个 MoE 走 qwen2_moe（Qwen2MoeForCausalLM）：num_experts=64、num_experts_per_tok=8，含共享专家。

# 文本栈维度与 7B 相同（hidden 3584 / 28层 / 28Q·4KV） # router → top-8 experts + shared expert # 总参数 57B · 每 token 激活 ~14B
其余尺寸为 Dense FFN。

⑥ 2-VL：M-RoPE 三维位置

2-VL 用多模态 RoPE：位置沿 (t,h,w) 三维拆分，mrope_section=[16,24,24][S-VL:918]。

# 图像按 patch 块计数、文本沿高度维 # 支持任意分辨率（动态分辨率） # vision tokens 填入 151655 位
详细见 §6 多模态。

6.2 M-RoPE 与动态分辨率

Qwen2VLModel.get_rope_index / compute_3d_position_ids（modeling_qwen2_vl.py:918, 1095）: 图像特征 → ViT(patch14) → spatial_merge 2×2 → image tokens 填入 input_ids 中 image_token_id=151655 位 位置 id 按 (t,h,w) 三维分别生成（mrope_section=[16,24,24]），文本沿 h 维递增 # 动态分辨率：非 448 固定切图，任意分辨率直接编码

融合后文本 LLM 收到统一 inputs_embeds 继续前向（Qwen2VLForConditionalGeneration.forward，:1267）。transformers v5 中 VL 模型须用 AutoModelForImageTextToText 加载。
