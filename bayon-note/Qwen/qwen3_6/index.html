Qwen3.6 家族架构详解

入口类 Qwen3_5ForConditionalGeneration（27B）/ Qwen3_5MoeForConditionalGeneration（35B-A3B） 2 个权重变体：27B Dense · 35B-A3B MoE 原生多模态：两变体均挂同一视觉塔（ViT×27 · patch16 · merge2） Gated DeltaNet + Gated Attention 3:1 混合（16 组 × 4 层） 词表 248,320 · 原生上下文 262,144 · YaRN 约 1,010,000 · MTP 代际主题：Thinking Preservation（preserve_thinking）· 发布 2026-04-22

本页以 官方 model card 的 config.json 实参（Qwen/Qwen3.6-27B、Qwen/Qwen3.6-35B-A3B，经 hf-mirror 逐字段核对）与 transformers 源码 modular_qwen3_5.py / modeling_qwen3_5.py（本地 E:\transformers）为唯一依据。Qwen3.6 架构图纸与 Qwen3.5 完全同构——27B 的 config 字段逐字节相同，换代集中在训练工艺与推理行为：稳定化、Agentic Coding 强化、Thinking Preservation。所有数字均标注来源（config 字段或源码文件:行号）。

1家族全景：27B / 35B-A3B 架构对照

两个变体均为组合 config（顶层 model_type + text_config + vision_config）。差异集中在：Dense vs MoE、hidden 维度、层数、专家路由；两种 token mixer、词表、RoPE 配置、视觉塔规格完全同构。

2端到端数据流总览

文本 token 与图像/视频像素两路输入 → 图像经视觉塔（ViT×27，patch 16）编码、空间合并 2×2、线性投影到文本 hidden → 与文本 embedding 经 masked_scatter 填入图像占位 token 位（early fusion）→ 统一序列进入 64 个解码层（35B-A3B 为 40 层）：每 4 层 3 个 Gated DeltaNet 线性层 + 1 个 Gated Attention 全注意力层 → 最终 RMSNorm → LM Head（248,320）。悬停节点看细节。

全家族统一主干：Embedding → DecoderLayer 堆叠 → 最终 RMSNorm → LM Head（无 tie）；多模态路径 early fusion，视觉特征不经过文本 embedding 查表，直接写入占位 token。

3解码层解剖：每 4 层一组的 3:1 混合块

层类型由 config.layer_types[layer_idx] 决定：值为 linear_attention 的层实例化 Qwen3_5GatedDeltaNet，值为 full_attention 的层实例化 Qwen3_5Attention；两类层都各接一个 FFN 子层（27B Dense / 35B-A3B MoE）。源码 modular_qwen3_5.py:357-410。

Qwen3_5DecoderLayer.forward（modular_qwen3_5.py:370-410）: residual = hidden_states hidden_states = input_layernorm(hidden_states) if block_type == "linear_attention": # 每 4 层中前 3 层 hidden_states = linear_attn(...) # Qwen3_5GatedDeltaNet elif block_type == "full_attention": # 每 4 层第 4 层 hidden_states, _ = self_attn(...) # Qwen3_5Attention（GQA + RoPE64） hidden_states = residual + hidden_states # ⊕1 residual = hidden_states hidden_states = post_attention_layernorm(hidden_states) hidden_states = mlp(hidden_states) # Dense SwiGLU / MoE 路由 hidden_states = residual + hidden_states # ⊕2 return hidden_states

注意：源码层循环不自己判 (i+1)%4==0——层类型是 config 里预生成好的 layer_types 列表，由 configuration_qwen3_5.py 的 __post_init__ 按 full_attention_interval=4 展开（modular_qwen3_5.py:138）。

4核心机制：Gated DeltaNet · 输出门控 · Thinking Preservation

① Gated DeltaNet（线性注意力，递归状态）

Qwen3_5GatedDeltaNet（modeling_qwen3_5.py:490）是 Qwen3.5/3.6/3.8 共享的线性注意力单元：query/key/value 投影到 16（QK）/48（V，27B）个头、head_dim 128；先过 causal conv1d（kernel 4）做局部归纳，再走 chunk 化门控 delta rule（torch_chunk_gated_delta_rule:287），跨块时递归回退（torch_recurrent_gated_delta_rule:424）。

x → in_proj → (q, k, v, a_log, dt_bias, g, ...) q,k,v = rotary_embed(q,k,v) # 位置注入 v = causal_conv1d(v) # 局部归纳，kernel=4 h_t = A·h_{t-1} + (v_t·sigmoid(g_t))·(σ(q_t)k_tᵀ) # 递归更新 y_t = h_t · σ(q_t) # 线性注意力输出 y = out_norm(y) → out_proj
设计意图：48/64 的层用递归状态把注意力复杂度从 O(n²) 降到接近 O(n)——262K 原生上下文与长程 agent 任务吞吐的关键。

② 输出门控（attn_output_gate = swish）

config 中 attn_output_gate=true、output_gate_type="swish"：注意力子层输出再经可学习门控与 swish 激活调制（modular_qwen3_5.py:208-340）。这是 Qwen3.5 起引入的稳定化手段，Qwen3.6 沿用同一配置。

attn_out = gate_proj(x) # 可学习门控 y = swish(attn_gate) ⊙ attn_out # swish 门控线性层稳定深层 GDN 训练 # 27B 与 35B-A3B 配置一致
稳定化：避免 GDN 递归状态在深堆叠中层间分布漂移。

③ 3:1 混合的工程意义

64 层中 48 层线性 + 16 层全注意力：线性层负责长上下文吞吐，每 4 层第 4 层的 Gated Attention 负责需要精确定位/回忆的路径（代码引用、文档回查）。官方 model card 的 Hidden Layout 原文：16×(3×(Gated DeltaNet→FFN)→1×(Gated Attention→FFN))。

linear 层（每 4 层前 3 层）：递归状态 O(n)，长上下文吞吐 full 层（每 4 层第 4 层）：标准 GQA 全注意力，精确召回 # 27B：48 线性 + 16 全 = 64 层 # 35B-A3B：30 线性 + 10 全 = 40 层
混合比例 3:1 在三代（3.5/3.6/3.8）间保持不变。

④ Thinking Preservation（本代主题）

Qwen3.6 训练时额外学习了保留并利用历史消息中的思考痕迹。默认 interleaved thinking 只保留最新一条用户消息触发的思考块；开启 preserve_thinking=True 后保留全部历史思考块并参与后续推理（agent 长程任务：决策更一致、减少重复推理、降低 token 消耗）。

默认（interleaved thinking）： 历史消息的思考块 → 只保留最新一条用户消息的思考块 API 入口：chat_template_kwargs 缺省 preserve_thinking=True： 历史消息的思考块 → 全部保留并参与推理 API 入口：chat_template_kwargs = {"preserve_thinking": True} # 注意：Qwen3.6 不官方支持 /think、/nothink 软切换 # 关闭思考用 enable_thinking=False # 官方建议上下文 ≥128K 以保留思考能力
官方原文（Qwen3.6-27B model card）：默认只保留处理最新用户消息时生成的思考块（interleaved thinking）；经额外训练可通过 preserve_thinking 保留历史思考痕迹。
