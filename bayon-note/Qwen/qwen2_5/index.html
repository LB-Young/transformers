1家族全景：六个尺寸的架构对照

Qwen2.5 文本栈与 Qwen2 共用 qwen2 model_type（0.5B 级 config 与 Qwen2-0.5B 同规格），差异在层数/维度规模与滑窗阈值 max_window_layers。本地锚点为 0.5B 与 2.5-VL-3B，其余尺寸来自官方 HF config（hf-mirror，2026-10-26 核验）。

2端到端数据流总览

文本 token 经 Embedding（151936 × d_model，小尺寸与 LM Head 共享）→ N 个 DecoderLayer（pre-norm RMSNorm → GQA 注意力 → 残差；再 RMSNorm → SwiGLU → 残差）→ 最终 RMSNorm → LM Head。2.5-VL 另起一路：图像/视频经 ViT（patch 14，window attention）编码、spatial merge 2×2 压成 image tokens，填入 image_token（151655）位，统一走多模态 RoPE。悬停节点看细节。

全家族统一主干：Embedding → DecoderLayer×N → 最终 RMSNorm → LM Head；文本栈与 Qwen2 同构（qwen2 模块），差异在层数/维度与是否挂带 window attention 的 ViT（2.5-VL）。

3解码层解剖：pre-norm RMSNorm 残差块

Qwen2.5 文本层（Qwen2DecoderLayer，modeling_qwen2.py:250-290）与 Qwen2 完全同构：两组 pre-norm 残差子层。六尺寸共享此结构，仅维度随尺寸缩放。

Qwen2DecoderLayer.forward（modeling_qwen2.py:261-290）: residual = hidden_states hidden_states = input_layernorm(hidden_states) hidden_states, _ = self_attn(hidden_states, position_embeddings, ...) hidden_states = residual + hidden_states # ⊕1 residual = hidden_states hidden_states = post_attention_layernorm(hidden_states) hidden_states = self.mlp(hidden_states) # SwiGLU hidden_states = residual + hidden_states # ⊕2 return hidden_states # 2.5-VL 文本层为 Qwen2_5_VLDecoderLayer（modeling_qwen2_5_vl.py:689），结构相同

4核心机制：GQA · 滑窗注意力 · 原生动态分辨率 · 多模态 RoPE

① GQA 分组与 repeat_kv

Qwen2.5 文本注意力与 Qwen2 一致：repeat_kv 把 K/V 从 KV 头复制到 Q 头数再做缩放点积注意力[S:130-140]。

Attn(Q,K,V) = softmax( QKᵀ / √d_k + mask ) V # 0.5B: 14Q / 2KV → repeat 7:1 # 72B: 64Q / 8KV → repeat 8:1 scaling = head_dim ** -0.5 # :178
分组比：0.5B 7:1、1.5B 6:1、7B 7:1、14B/32B 5:1、72B 8:1。

② 滑窗注意力（layer_types 分层）

v5 的 Qwen2Config.__post_init__ 按层索引生成 layer_types：当 sliding_window is not None 且 i >= max_window_layers 时为 sliding_attention[CFG:88-94]。

layer_types = ["sliding_attention" if (sliding_window is not None and i >= max_window_layers) else "full_attention" for i in range(num_hidden_layers)] # Qwen2.5-0.5B: 24 层, max_window_layers=21（顶部 3 层滑窗） # Qwen2.5-72B: 80 层, max_window_layers=70（顶部 10 层滑窗）
踩坑：本机与官方 config 均 use_sliding_window=false → v5 全层 full_attention。

③ RMSNorm 与 SwiGLU

RMSNorm 先 fp32 归一，再乘 γ[S:230-247]。FFN 为三投影门控 SwiGLU（silu）[S:34-48]。

rms(x) = sqrt( mean(x²) + eps ) y = γ · x / rms(x) FFN(x) = down( silu(gate(x)) ⊙ up(x) )
hidden_act=silu；eps=1e-6。

④ RoPE（θ=1e6）与多模态 RoPE

文本旋转位置编码基频 rope_theta=1000000.0。2.5-VL 用多模态 RoPE：mrope_section=[16,24,24]，位置沿 (t,h,w) 三维拆分[S-VL:501,941]。

inv_freq_i = base ^ (-2i / head_dim), base=1e6 q_rot = q·cos θ + rotate_half(q)·sin θ # 2.5-VL: mrope_section=[16,24,24]（t,h,w 三段）

⑤ 原生动态分辨率

2.5-VL 不做 448 固定切图：按 patch 14×14 直接切任意分辨率图像，经 ViT window attention（窗 112，全局块 7/15/23/31）编码，再 spatial merge 2×2。

# ViT window attention（窗 112） # 全局块：fullatt_block_indexes = [7,15,23,31] # 支持高分辨率文档与长视频 # 文本栈上下文扩到 128K
详细见 §6 多模态。

⑥ 2.5-VL：视觉塔 window attention

2.5-VL 视觉塔 32 块中仅 7/15/23/31 为全局注意力，其余窗 112[S-VL:338]。

# Qwen2_5_VisionTransformerPretrainedModel（:383） # window_size=112，fullatt_block_indexes=[7,15,23,31] # out_hidden_size 对齐文本 hidden
比 2-VL 的全局注意力更省算力。
