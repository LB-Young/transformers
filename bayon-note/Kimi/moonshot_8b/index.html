7演进视角：Moonshot 早期真实开源模型对照

moonshotai 组织在 2025 年初真实开源的文本/稀疏模型是 Moonlight-16B-A3B（2025-02/03，Muon 优化器首次大规模训练实践配套），并非名为「Moonshot-8B」的 dense 模型。其官方 config 实测值（留档 _tools\_cfgpull\）：hidden 2048 / 27 层 / 16Q·16KV / inter 11264 / moe_inter 1408 / 64 路由+2 共享 top-6 / kv_lora 512 / vocab 163840 / max 8192 / ropeθ 50000。

若任务书的「Moonshot-8B」实为对早期开源模型的误记，最接近的真实对象是 Moonlight-16B-A3B（16B 总 / 3B 激活 MoE，非 8B dense）。本页不做替换，仅作对照。系列内其他官方模型见 Kimi-K2-0905 笔记演进章。
