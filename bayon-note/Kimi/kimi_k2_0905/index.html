DeepseekV3ForCausalLM · model_type=kimi_k2 1T 总参 / 32B 激活 · 384 路由专家 + 1 共享 · top-8 MLA：kv_lora 512 · q_lora 1536 · nope128 · rope64 · v128 hidden 7168 · 61 层 · 词表 163840 · 上下文 262144（YaRN）

本页以 Kimi-K2-Instruct-0905 官方 config.json（2026-10-31 经 hf-mirror 拉取，留档 _tools\_cfgpull\）与 transformers 源码 models\deepseek_v3\（本地 E:\transformers 同架构等价实现）为唯一依据。K2 系列技术事实以官方论文 arXiv:2507.20534 为准。关键特点：0905 复用 DeepSeek-V3 实现代码（architectures=DeepseekV3ForCausalLM，auto_map 指向官方仓库 modeling_deepseek.py），本地 transformers 无原生 kimi_k2 模块。所有数字均标注来源。

2端到端数据流总览

文本 token → 词嵌入（untied）→ 第 0 层 dense 解码层（MLA 注意力 + 18432 维 SwiGLU FFN）→ 层 1–60 MoE 解码层（MLA 注意力 + 384 路由专家选 8 / 1 共享专家）→ 最终 RMSNorm → LM Head（7168→163840，untied）。

全模型统一主干如上；差异集中在 FFN 子层：第 0 层是 dense SwiGLU（18432），其余 60 层是 top-8 细粒度 MoE。

3解码层解剖：DeepSeek-V3 式前置 RMSNorm 残差块

解码层与 DeepSeek-V3 同构（本地等价实现 DeepseekV3DecoderLayer，models\deepseek_v3\modeling_deepseek_v3.py:485）：每组含注意力与 FFN 两个残差子层，均为单 RMSNorm 前置。第 0 层 FFN 是 dense SwiGLU（18432），其余层 FFN 是 MoE。

DecoderLayer.forward（DeepSeek-V3 式，等价实现 modeling_deepseek_v3.py:485 起）: residual = hidden_states hidden_states = input_layernorm(hidden_states) # RMSNorm(7168, eps 1e-5) hidden_states, _ = self_attn(hidden_states) # MLA：低秩压缩 + RoPE hidden_states = residual + hidden_states # ⊕1 residual = hidden_states hidden_states = post_attention_layernorm(hidden_states) # 第 0 层：dense MLP(18432)；其余层：MoE(384 路由选8 + 1 共享, moe_inter 2048) hidden_states = self.mlp(hidden_states) hidden_states = residual + hidden_states # ⊕2 return hidden_states

4核心机制：MLA 低秩压缩 · 384 专家路由 · YaRN 扩长

① MLA：Q/KV 低秩联合压缩

注意力先把 hidden 压到低秩隐向量再解多头（等价实现 DeepseekV3Attention，:349-394）。

q = W_qB · x ∈ R^1536 # q_lora_rank cKV = W_KV · x ∈ R^512 # kv_lora_rank cKV → RMSNorm → split(512, 64) # 64 = qk_rope_head_dim q' = RMSNorm(q) · W_qA # KV cache 只缓存 512 维低秩隐向量
RoPE 只作用在拆分出的 64 维 qk_rope_head_dim 段；其余 128 维 qk_nope 不带位置编码（:389,445）。

② MoE 路由：384 路由选 8 + 1 共享

MoE 块（等价实现 DeepseekV3MoE，:201；专家 MLP :104-157）。

logits = x @ W_gate^T # (seq, 384) scores = sigmoid(logits) # scoring_func=sigmoid w, idx = noaux_tc_topk(scores, k=8) # topk_method=noaux_tc w = w * routed_scaling_factor(2.827) # :157 w = w / w.sum(-1) # norm_topk_prob=true # 384 路由专家分桶计算；另有 1 共享专家对所有 token
论文（arXiv:2507.20534）：固定激活参数下扩大路由专家总数（稀疏度 384/8=48）可降低 loss，故采用 384 路由专家。

③ YaRN 扩长到 262144

rope_theta = 50000 rope_scaling = { type:"yarn", factor:64.0, original_max_position_embeddings:4096, beta_fast:1.0, beta_slow:1.0, mscale:1.0 } max_position_embeddings = 262144
K2-Base 原生 max 为 131072；0905 通过 YaRN（factor 64，基准 4096）把有效上下文扩到 262144。

5注意力机制：MLA（非 GQA）· 64 头 · 无注意力偏置

维度取值含义
num_attention_heads (Q)64Q 头数
num_key_value_heads64名义 KV 头（MLA 下共享低秩 KV 隐向量）
q_lora_rank1536Q 低秩压缩维
kv_lora_rank512KV cache 实际缓存量
qk_nope / qk_rope / v_head dim128 / 64 / 128每头分段维度
attention_biasfalseQ/K/V/O 投影均无偏置
Attn(Q,K,V) = softmax( QK^T / sqrt(d_hk) + mask ) V # MLA 下 Q 经 q_a_layernorm 后上投影为 64 头； # KV 隐向量 512 维与 rope 段 64 维拼接后再扩为多头；因果掩码，无滑窗（全注意力）。

与普通 GQA 的区别：GQA 是 Q 多头、KV 分组共享；MLA 是 Q/KV 都先压到低秩瓶颈再解多头，KV cache 体积由 kv_lora_rank=512 决定，而非头数×head_dim。
