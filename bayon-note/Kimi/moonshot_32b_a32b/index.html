7演进视角：与真实早期开源模型对照

任务书称该模型「2025-03 开放权重、与 Kimi K1.5 同代技术」。核验显示：Kimi k1.5（arXiv:2501.12599）本身未开放权重；2025 年初 Moonshot 真实开源的稀疏模型是 Moonlight-16B-A3B（2025-02/03，Muon 配套）。其官方 config 实测值（留档 _tools\_cfgpull\Moonlight-16B-A3B.config.json）：hidden 2048 / 27 层 / 64 路由+2 共享 top-6 / moe_inter 1408 / kv_lora 512 / vocab 163840 / max 8192 / ropeθ 50000。

若任务书的「Moonshot-32B-A32B」实为对早期开源模型的误记，最接近的真实对象是 Moonlight-16B-A3B（16B 总 / 3B 激活 MoE）；而「A32B」语义上与后续 Kimi-K2（1T 总 / 32B 激活）一致。本页不做替换，仅作对照。系列内其他官方模型见 Kimi-K2-0905 笔记演进章。
