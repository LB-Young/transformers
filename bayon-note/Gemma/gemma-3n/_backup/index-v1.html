Gemma 3n（E2B-it）架构详解 — Transformers 源码级核对版

入口类 Gemma3nForConditionalGeneration 文本 30 层 · d=2048 · GQA 8Q/2KV 视觉 timm MobileNetV5-300M · 音频 SSCP+Conformer×12 本文数字逐一对到 config.json 与 modeling_gemma3n.py 行号

Gemma 3n 是 Google 面向端侧（手机/笔记本）的开放权重多模态模型。本页以本地权威权重 gemma-3n-E2B-it/config.json 为准，逐字段核对 src/transformers/models/gemma3n/modeling_gemma3n.py 的真实实现：文本骨干为 MatFormer 嵌套 Transformer（AltUp 四输入 + LAuReL 低秩增强残差 + 逐层 PLE 门控），混合注意力为「4 层滑窗 512 + 1 层全局」交错，末 10 层共享 KV；视觉塔输出 256 个 soft token、音频塔输出至多 188 个 soft token，经各自投影层嵌入 2048 维文本流。下文所有维度、公式、类名均标注 config 路径或源码文件:行号。

1端到端数据流总图

三条输入支路：文本（离散 token）、视觉（pixel_values）、音频（mel 频谱）。视觉/音频特征在 embed_vision / embed_audio 中投影到文本 2048 维空间，再以 masked_scatter 填进序列中 image_token_id / audio_token_id 的占位位置（源码 modeling_gemma3n.py:2110、:2136）。

注意三个常被写错的点：① 视觉塔 hidden_size 本身就是 2048（config vision_config.hidden_size=2048），所以 embed_vision 的投影是 2048→2048，不是 1152→2048；② 音频塔 hidden_size=1536，embed_audio 才做 1536→2048 升维；③ 主词嵌入不是普通嵌入，而是 Gemma3nTextScaledWordEmbedding，前向时乘以 √d（modeling:918-929, :1602-1604）。

2单个解码层内部结构（Gemma3nTextDecoderLayer）

源码 modeling:1273-1346。这是 MatFormer 的核心单元：每个层同时维护 4 路 AltUp 隐藏态，残差路径上叠加 LAuReL 低秩分支，FFN 门控带高斯 top-k 稀疏，末尾再用 PLE（逐层小嵌入）做门控注入。

残差公式（源码 :1323-1324）：先 attn_gated = active + attn，再 attn_laurel = (attn_gated + laurel_output) / √2。注意力缩放系数 self.scaling = 1.0（:1173），因为 Q/K 各自经过 RMSNorm（q_norm / k_norm / v_norm，:1194-1205），不再用 1/√d 缩放。

330 层分布时间线（E2B）

分层区间（1-based）注意力类型激活稀疏KV
第 1–10 层滑窗 512 / 每第 5 层全局0.95（gate 高斯 top-k）正常独立 K/V
第 11–20 层滑窗 512 / 每第 5 层全局0.0（稠密）正常独立 K/V
第 21–30 层滑窗 512 / 每第 5 层全局0.0（稠密）共享：复用前一同类层 K/V，无 k/v 权重

全局层 = 第 5/10/15/20/25/30 层（共 6 层），滑窗层 24 层。来源：config text_config.layer_types、activation_sparsity_pattern；KV 共享区间计算 first = 30 − 10 = 20（0-based），即 1-based 第 21 层起 modeling:1177-1178。

6关键机制（含可复算公式/维度）

MatFormer 嵌套与 AltUp 四输入

每个层同时维护 altup_num_inputs=4 路隐藏态：第 0 路是词嵌入，第 1–3 路由 altup_projections（3 个 2048→2048 Linear）生成并做幅值归一化堆叠成 [4,B,T,2048]。层内 predict 用可学习系数矩阵预测 4 路输出，correct 再用真实残差修正；层末尾经 3 个 altup_unembed_projections 后对 4 路取均值输出。

stack = [h₀, P₁h₀, P₂h₀, P₃h₀] → … → out = meanᵢ( Uᵢ·hᵢ )
modeling:1631-1637（投影）、1711-1721（堆叠）、1015-1072（predict/correct）、1749-1759（均值）

LAuReL 低秩增强残差（rank 64）

在注意力子层前，对归一化输入额外走一条低秩瓶颈：2048→64→2048，再过 RMSNorm，作为增强残差加回主路。仅 2×2048×64≈0.26M 参数/层，显著改变信息流。

y = x + RMSNorm( W₂·ReLU?·W₁·x )，W₁:2048→64, W₂:64→2048
modeling:932-947；config laurel_rank=64

高斯 top-k 激活稀疏（前 10 层 0.95）

仅作用于 gate_proj 输出：按正态分布分位点 Φ⁻¹(0.95) 求阈值，把低于阈值的门控值直接置零（ReLU(x−cutoff)），实现 95% 稀疏；第 11–30 层稀疏率 0，稠密。

cutoff = mean(g) + std(g)·Φ⁻¹(0.95)；g ← ReLU(g − cutoff)
modeling:964-985；config activation_sparsity_pattern [0.95]×10+[0.0]×20

共享 KV（末 10 层）

第 21–30 层不再拥有 k_proj/v_proj（权重直接不建，_keys_to_ignore_on_load_unexpected 会跳过加载），而是复用进入共享区前最后一个同类型层（滑窗↔滑窗、全局↔全局）算好的 K/V。

shared_from = 30 − 10 = 20（0-based）→ 层 idx≥20 复用 shared_kv_states[type]
modeling:1177-1189, 1232-1250, 1642-1648

混合注意力 + 双 RoPE

每 5 层一组：前 4 层滑窗（窗口 512，因果滑窗掩码），第 5 层全局。RoPE 基频按层类型分别缓存：全局层 θ=1e6，滑窗层 θ=1e4。

inv_freq(full)=1/(1e6^(2i/256))；inv_freq(sliding)=1/(1e4^(2i/256))
configuration:191-200；modeling:1529-1588, 1699-1702

PLE 逐层嵌入门控

一张大查表 Emb(262144, 30×256) reshape 成每层一条 256 维向量；层内先把主隐态门控到 256 维、与该层查表向量逐元素相乘，再投回 2048 维。可整体预计算并卸载到 CPU。

z = act(Gate₂₀₄₈→₂₅₆·h) ⊙ p_layer； h ← Proj₂₅₆→₂₀₄₈(RMSNorm(z))
modeling:1616-1621, 1767-1799, 1336-1344

视觉塔 → 256 soft token

timm MobileNetV5-300M 主干输出特征图 reshape 为 [B,256,2048]（即 16×16 网格展平），乘 √2048 后经 embed_vision（RMSNorm→Linear 2048→2048→norm）注入序列中 256 个 image_token 占位处。

F_img = tower(pixels) → [B,2048,16,16] → [B,256,2048]×√2048 → embed
modeling:1956-1974, 2105-2110

音频塔 → 至多 188 soft token

128 维 mel 频谱先经 2 个 SSCP 卷积（步长 (2,2)，时间/频率各降采样 4×），过 12 个 Conformer 块（d=1536，8 头，块内注意力 logit cap 50），时间维再 ÷4，得到至多 188 帧 ×1536；经 embed_audio 升 2048 维，不足 188 用最后一条硬嵌入补齐。

T_out ≤ 188； F_audio = embed_audio( [B,≤188,1536] ) → pad 到 188
modeling:1448-1526, 2113-2136；config audio_config

输出端 logit soft-capping（=30）

LM Head 与主词嵌入共享权重（tied）。输出 logits 先除以 30、过 tanh、再乘 30，压到 ±30 后送交叉熵，抑制极端 logit。注意：文本注意力内部没有 softcap（仅音频 Conformer 有 cap=50）。

logits ← 30 · tanh( logits / 30 )
modeling:2296-2300（条件生成）、1865-1868（CausalLM）；tied 1804/2195
