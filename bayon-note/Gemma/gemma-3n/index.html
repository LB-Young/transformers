Gemma 3n 家族架构详解 — E2B / E4B 全尺寸

入口类 Gemma3nForConditionalGeneration 两个尺寸：E2B（有效≈2B）· E4B（有效≈4B） 原生三路：文本 + 图像(MobileNetV5-300M) + 音频(Conformer×12) MatFormer 嵌套 · AltUp · LAuReL(rank64) · PLE · 激活稀疏

本页以本地检查点 gemma-3n-E2B-it/config.json（权威基准）、ModelScope 下载的 google/gemma-3n-E4B-it/config.json，以及本地 transformers 源码 modeling_gemma3n.py / configuration_gemma3n.py 为唯一依据。Gemma 3n 是 Google 面向端侧（手机/笔记本）的开放权重多模态模型：文本骨干是 MatFormer 嵌套 Transformer（AltUp 四输入 + LAuReL 低秩增强残差 + 逐层 PLE 门控 + 前 10 层高斯 top-k 激活稀疏），混合注意力为「4 层滑窗 512 + 1 层全局」交错、末段共享 KV；视觉塔输出 256 个 soft token、音频塔输出至多 188 个 soft token。下文所有数字逐字段标注 config 来源，所有机制标注源码文件:行号。

2端到端数据流总览（文本 + 图像 + 音频三路）

三路输入：文本 input_ids、图像 pixel_values、音频 input_features。视觉/音频特征经各自 embedder（Gemma3nMultimodalEmbedder）投影进 2048 维文本空间，再以 masked_scatter 填进序列中 image_token_id=262145 / audio_token_id=262273 的占位位。主干：嵌入 ×√d → AltUp 四路线堆叠 → N 个解码层 → 四分支求均值 → 最终 RMSNorm → 共享 LM Head → softcap 30。悬停节点看细节与源码行号。

全家族统一主干：嵌入(×√d) → AltUp 4 路 → 解码层×N → 四分支均值 → RMSNorm → 共享 LM Head → softcap 30；E2B/E4B 差异仅在层数、FFN 中间维、KV 共享层数。

4核心机制专节（本代独有）

MatFormer 嵌套：intermediate_size 逐层数组

config.intermediate_size 是逐层数组：每层 MLP 取 intermediate_size[layer_idx]（modeling:955）。配置类允许标量（自动广播成 N 层，configuration:138-139）或显式 N 元列表（长度校验，configuration:131-137）。这是 MatFormer「嵌套子模型」的载体：理论上可对不同层配不同 FFN 中间维以抽取嵌套子网络；但发货的 E2B/E4B 检查点内部各层同值——E2B 全 30 层 8192，E4B 全 35 层 16384。

mlp 中间维 = config.intermediate_size[layer_idx] E2B: [8192]×30 E4B: [16384]×35
config text_config.intermediate_size；modeling:955；configuration:131-139

AltUp：Alternating Updates（altup_num_inputs=4）

每个解码层同时维护 4 路隐藏态（[4,B,T,2048]）：第 0 路是词嵌入，第 1–3 路由 3 个 altup_projections（2048→2048 Linear）生成并做幅值归一化（对齐第 0 路 RMS）。层内 predict 用 modality_router(tanh) 预测 4×4 系数矩阵做可学习混合；correct 再用真实残差 innovation=activated−prediction 修正 4 路；层末 4 路经 unembed 投影后求均值出主干。论文出处见 modeling:989-997 注释（NeurIPS 2023）。

stack=[h0, P1h0, P2h0, P3h0] # 幅值对齐, :1711-1721 predictions = altup.predict(stack) # :1015-1041 corrected = altup.correct(predict, resid) # :1043-1072 out = mean_i( unembed_i(corrected_i) ) # :1747-1759
config altup_num_inputs=4 / active_idx=0 / coef_clip=120；modeling:988-1084,1631-1637,1711-1759

AltUp 计算流程详解（五步，从输入到输出）

本节 2026-11-03 补充，逐行核对 modeling_gemma3n.py；config 实测补充 altup_correct_scale=True（可学习输出缩放，初始 0）。

第 0 步 · 构建 4 路 stack（仅输入时一次） :1705-1721：h0 = inputs_embeds（ScaledEmbedding 已乘 √2048，:1602-1604）。以第 0 路 RMS 幅值为基准 target = mean(h0²)^0.5；对 i=1,2,3 用 3 个 altup_projections[i]（2048→2048 Linear，:1631-1633）投影 h0，并做幅值归一化，防止投影改变激活尺度。堆叠为 stack=[h0,h1,h2,h3]，形状 [4,B,T,2048]。此后每一层输入输出都是这个 4D stack。

h_i = P_i(h0) · target / max( sqrt(mean(P_i(h0)²)), 1e-5 ) # 幅值对齐, :1716-1719

第 1 步 · predict：可学习混合猜测本层输出 :1015-1041, :1306：① 路由 m = tanh(W_router(RMSNorm(h0)/2048)) → [B,T,4]（每 token 一个 4 维路由权重，:1010-1013）；② 系数 A = W_pred(m) → reshape [B,T,4,4]（每 token 一张 4×4 混合矩阵）；③ 预测 P_j = Σ_i A[j,i]·h_i + h_j（4 路加权和 + 自身残差）；④ 取 active 路 active = P[0]（altup_active_idx=0）。训练时 W_pred clamp ±120（altup_coef_clip）。

第 2 步 · 贵算子只跑第 0 路 :1309-1329：注意力 / LAuReL / FFN 全部只作用在 P[0] 上（其余 3 路旁观不参与）：

z = input_layernorm(active) # :1309 lrl = z + post_laurel_norm(W2·W1·z) # :1310 LAuReL 2048→64→2048 attn = post_attn_norm(self_attn(z)) # :1312-1321 attn_laurel = (active + attn + lrl) / √2 # :1323-1324 y = attn_laurel + post_ffn_norm(mlp(pre_ffn_norm(attn_laurel))) # :1326-1329

y 即本层真实输出（源码中称 activated）。

第 3 步 · correct：残差修正分发回 4 路 :1043-1072, :1330-1344：① 预测误差 ε = y − P[0]，复制 4 份（:1056-1057）；② 修正系数：用真实输出 y 重算路由 m′，c = W_corr(m′) + 1.0 → [B,T,4]（+1 保证初始≈纯残差传播；训练时 clamp ±120）；③ Q_i = P_i + c_i·ε（每路 = 预测 + 自己系数的修正量）；④ PLE 注入：first = Q[0] 乘可学习 correct_output_scale（初始 0，altup_correct_scale=True 时启用，:1332-1334）→ gate 2048→256 ⊙ 逐层查表向量 → 投回 2048 → post norm → 只加到 Q[1:]（第 0 路不加，:1336-1344）。返回 Q（[4,B,T,2048]）进下一层。

第 4 步 · 输出合并：四路求均值 :1747-1759：以 Q[0] RMS 幅值为基准；i=1..3 过 altup_unembed_projections[i]（2048→2048，:1635-1637）+ 幅值对齐；out = mean([Q0,Q1′,Q2′,Q3′], dim=0) → [B,T,2048] → 最终 RMSNorm → 共享 LM Head → softcap(30)。

AltUp 的作用

作用机制收益
计算效率（端侧核心动机）注意力/FFN/LAuReL 每层只跑第 0 路预测，其余 3 路用便宜 Linear+系数混合同步更新4 路表征 ≈ 1 份贵计算
可学习稀疏更新（论文核心）predict 先猜、correct 用真实残差 ε 修正；训练让预测越准 → 修正越稀疏层间更新低秩化/稀疏化（NeurIPS 2023）

与激活稀疏的边界：激活稀疏（前 10 层高斯 top-k）作用于 FFN 门控中间维；AltUp 稀疏的是层间更新本身，二者可叠加。

PLE：Per-Layer Embeddings（逐层嵌入）

一张大查表 embed_tokens_per_layer = Embedding(262144, N×256)（×√256），reshape 成每层一条 256 维向量；另有一条从主嵌入投影而来的分支，二者相加 ×1/√2。层内把主隐态经 gate 压到 256 维、与该层查表向量逐元素相乘，再投回 2048 维注入。可整体预计算并卸载到 CPU。

ple_lookup = Emb(262144, N·256) → [B,T,N,256] # :1616-1621,1767-1772 ple = (proj_norm(proj(h0)) + ple_lookup)·(1/√2) # :1774-1799 z = proj256→2048( act(gate2048→256 h) ⊙ ple_l ) # :1337-1342
config hidden_size_per_layer_input=256 / vocab_size_per_layer_input=262144；modeling:1616-1621,1767-1799,1336-1344

激活稀疏：高斯 top-k（前 10 层 cutoff 0.95）

仅作用于 GeGLU 的 gate_proj 输出：按正态分布分位点 Φ⁻¹(0.95) 求阈值，低于阈值的门控值经 ReLU(x−cutoff) 直接置零——即中间维约 95% 维度在每 token 上被关掉。E2B/E4B 均为前 10 层 sparsity=0.95、其后稠密（0.0）（配置默认规则 configuration:146-150）。注意 up_proj 不稀疏，稀疏的是门控支路。

cutoff = mean(g) + std(g)·Normal(0,1).icdf(0.95) # :982-984 g ← ReLU(g − cutoff) # :985 # E2B: [0.95]×10+[0.0]×20 ; E4B: [0.95]×10+[0.0]×25
config activation_sparsity_pattern；modeling:962-985；configuration:146-156

LAuReL：Learned Augmented Residual Layer

在注意力子层前，对归一化输入额外走一条低秩瓶颈增强残差：laurel_rank=64，即 2048→64→2048，再过 post RMSNorm，最后与主残差在 /√2 处合并。每层仅 2×2048×64≈0.26M 参数，却显著改变信息流。

laurel_output = z + post_norm( W2·W1·z ) # :943-947 attn_laurel = (active+attn + laurel_output)/√2 # :1324
config laurel_rank=64；modeling:932-947,1310,1324

共享 KV（末段层）

末段层不再拥有 k_proj/v_proj/k_norm/v_norm（权重直接不建，_keys_to_ignore_on_load_unexpected 跳过加载），而是复用进入共享区前最后一个同类型层（滑窗↔滑窗、全局↔全局）算好的 K/V 状态。E2B 共享后 10 层（第 21–30 层），E4B 共享后 15 层（第 21–35 层）。

first_shared = num_layers − num_kv_shared_layers # :1177 E2B: 30−10=20(0-based) → 1-based 21..30 E4B: 35−15=20(0-based) → 1-based 21..35 k,v = shared_kv_states[same_type_last_non_shared] # :1232-1236
config num_kv_shared_layers=10/15；modeling:1177-1189,1232-1250,1642-1648

双 RoPE 基频（按层类型）

位置编码按层类型分别缓存逆频率：全局层用 rope_theta=1e6，滑窗层用 rope_local_base_freq=1e4。configuration:182-200 把它们映射进 rope_parameters[layer_type]["rope_theta"]。

inv_freq(full) = 1/(1e6^(2i/256)) # θ=1e6 inv_freq(sliding) = 1/(1e4^(2i/256)) # θ=1e4 # modeling:1529-1588；configuration:193-200
config rope_theta=1e6 / rope_local_base_freq=1e4

输出端 logit soft-capping（=30）

LM Head 与主词嵌入共享权重（tied）。输出 logits 先除以 30、过 tanh、再乘回 30，压到 ±30 抑制极端 logit。注意：文本注意力内部没有 softcap（仅音频 Conformer 内部有 logit cap=50）。

logits ← 30 · tanh( logits / 30 ) # :2297-2300
config final_logit_softcapping=30.0；modeling:2296-2300；tied :2195

5注意力机制：GQA + 每 5 层 1 full + 共享 KV

Gemma 3n 注意力（modeling:1162-1270）：Q/K/V 各经 head-wise RMSNorm（q_norm/k_norm/v_norm），scaling=1.0（取代 Gemma 2/3 的显式 query 缩放）；Q 8 头、K/V 2 头（GQA 组比 4:1），head_dim=256。

层模式E2B（30 层）E4B（35 层）
sliding_attention 层24 层，窗口 512，RoPE θ=1e428 层，窗口 512，RoPE θ=1e4
full_attention 层（1-based）第 5,10,15,20,25,30（6 层），全局因果，θ=1e6第 5,10,15,20,25,30,35（7 层），全局因果，θ=1e6
KV 共享层第 21–30 层（10 层），无 k/v 权重第 21–35 层（15 层），无 k/v 权重
投影维度q: 2048→8×256=2048；k/v: 2048→2×256=512；o: 2048→2048（共享层仅 q/o 有）

层类型由 config layer_types 显式给出；缺省时配置类规则为「每 5 层第 5 层 full」（configuration:141-144）。滑窗层用 create_sliding_window_causal_mask、全局层用普通因果掩码（modeling:1699-1702）。

6多模态：MobileNetV5 视觉塔 + Conformer 音频塔

6.1 视觉塔（两尺寸一致）

与 Gemma 3 使用的 ViT 系 SigLIP/SoViT 不同，Gemma 3n 面向端侧改用轻量 CNN 主干 timm MobileNetV5-300M（vision_config.architecture=mobilenetv5_300m_enc，hidden=2048）。输出特征图 [B,2048,16,16] reshape 为 [B,256,2048]，乘 √2048 后经 embed_vision（RMSNorm→Linear 2048→2048→RMSNorm）注入 256 个 image_token 占位位（modeling:1956-1974）。

6.2 音频塔（两尺寸一致，端侧原生）

Gemma 3n 相比 Gemma 3 新增端侧原生音频：128 维 mel 频谱先经 2 层 SSCP 卷积（通道 [128,32]，3×3 stride (2,2)）下采样，过 12 个 Conformer 块（hidden=1536，8 头，块内 attention logit cap=50，chunk=12/左上下文 13，残差权重 0.5），时间维再 ÷4（conf_reduction_factor=4），得到至多 188 帧 ×1536；经 embed_audio（RMSNorm→Linear 1536→2048→RMSNorm）升维，不足 188 用最后一条硬嵌入补齐（modeling:1448-1526, 2167）。
