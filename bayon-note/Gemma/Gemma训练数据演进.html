预训练、指令微调与强化学习数据的四代演变。从英文单模态的 3T token 基本盘，到多语言、图文音多模态与思维链数据，Gemma 系列用四代技术报告画出一条完整的数据演进路线。

PART 01 · 总览

01四代演进的时间轴

以发布时间为轴，四代模型在数据规模、数据构成、合成策略与对齐信号上逐级升级。每个节点对应其预训练、指令微调与强化学习数据的关键动作。

2024-02
Gemma 1

英文单模态奠基

2B = 3T tokens · 7B = 6T tokens
  • 预训练：英文网页、数学、代码；启发式 + 模型分类器过滤；分阶段训练提升后期数据质量
  • SFT：纯文本纯英文，人工 + 合成 prompt-response 对；LM 逐对评估选混合
  • RLHF：人工英文偏好对 + Bradley-Terry 奖励模型；高容量模型自动评分
2024-06
Gemma 2

蒸馏时代开启

2B = 2T · 9B = 8T · 27B = 13T tokens
  • 预训练：网页、代码、科学文章；新增知识蒸馏（教师概率到学生分布）
  • SFT：扩展 Gemma 1.1 数据；LMSYS-chat-1M 提示（不含回答）；行为克隆 + 学生分布蒸馏
  • RLHF：奖励模型比 policy 大一个数量级、面向多轮对话；阶段后模型平均
2025-03
Gemma 3

多语言与图文混合

1B = 2T · 4B = 4T · 12B = 12T · 27B = 14T tokens
  • 预训练：图文混合；多语言单语 + 平行语料；质量重加权；每 token 256-logit 采样蒸馏
  • SFT：从大型 IT 教师改进版知识蒸馏，与 RL 阶段衔接
  • RL：BOND / WARM / WARP 改进版；多奖励（人类反馈、代码执行、数学真实答案）
2026-07
Gemma 4

多模态与思维链

web / 代码 / 图像 / 音频 · cutoff 2025-01 · 预算未披露
  • 预训练：类似 Gemma 3 配方；跨域跨模态数据（E2B / E4B / 12B 含音频）
  • SFT：类似 Gemma 3；新增 thinking mode 思维链数据
  • RL：类似 Gemma 3；思维链推理轨迹数据

06三阶段数据管道演进全景

预训练、SFT 与强化学习三个阶段的数据管道在四代中的演进路径。

GEMMA 1

奠基

  • 预训练：英文 3T/6T，启发式+分类器过滤
  • SFT：人工+合成对，LM 逐对评估
  • RL：偏好对 + Bradley-Terry
GEMMA 2

蒸馏

  • 预训练：13T/8T/2T + 知识蒸馏
  • SFT：行为克隆 + LMSYS 提示
  • RL：更大对话向奖励模型 + 模型平均
GEMMA 3

多模态

  • 预训练：图文混合 + 质量重加权 + 采样蒸馏
  • SFT：大 IT 教师蒸馏
  • RL：BOND/WARM/WARP + 多奖励
GEMMA 4

思维链

  • 预训练：跨域多模态，预算未披露
  • SFT：继承 + thinking mode 数据
  • RL：继承 + 推理轨迹
PART 06 · 结论

07五条演进主线

规模扩张

token 预算逐代提升：3T/6T → 2T/8T/13T → 2T/4T/12T/14T → 未披露

构成扩展

英文单语 → 多语言（单语+平行）→ 图文音多模态

合成策略深化

人工混合 → 行为克隆 → 大型教师蒸馏主导

对齐信号多元

偏好对 → 更大对话向奖励模型 → 多奖励融合 + 思维链

治理贯穿

过滤管道与事实性子集四代沿用，逐步加入质量重加权
