—— PART 01 · 总览

01 四代训练算法的时间轴

以发布时间为轴，四代模型在预训练目标、指令微调方法与强化学习对齐算法上逐级升级；每个节点列出三阶段的算法关键动作。

2024-02
Gemma 1

奠基：标准训练 + 经典 RLHF

  • 预训练：标准 next-token 预测；分阶段训练提升后期数据质量
  • SFT：标准监督微调；LM 逐对评估（大模型判优）选数据混合
  • RL：经典 RLHF；Bradley-Terry 奖励模型 + 未命名新颖算法；高容量模型自动评分
2024-06
Gemma 2

蒸馏时代开启

  • 预训练：首次引入知识蒸馏，min Σx −P_T·log P_S（Gemini 1.5 同法）
  • SFT：行为克隆 + on-policy 蒸馏（Agarwal 2024；Gu 2024）
  • RL：同 Gemma 1.1 算法；奖励模型大一个数量级、更对话向；阶段模型平均
2025-03
Gemma 3

采样蒸馏 + 多奖励

  • 预训练：每 token 256-logit 加权采样蒸馏；QAT 量化感知训练
  • SFT：大型 IT 教师改进版蒸馏，与 RL 阶段衔接
  • RL：BOND / WARM / WARP 改进版；多奖励（人类反馈、代码执行、数学真实答案）
2026-07
Gemma 4

配方继承 + 思维链 + 工程升级

  • 预训练：继承 Gemma 3 蒸馏配方；QAT 扩展至编码器与更低 bit 位宽
  • SFT：同 Gemma 3；新增 thinking mode 推理轨迹数据
  • RL：同 Gemma 3；思维链推理轨迹贯穿对齐；MTP drafter 推测解码
—— PART 02 · 预训练

02 预训练算法：从标准训练到采样蒸馏

训练目标从无蒸馏的标准 next-token 预测，演进出全词汇概率蒸馏与 256-logit 加权采样蒸馏两代升级；量化感知训练自 Gemma 3 起进入管道。

Gemma 1

2024-02 · 奠基

标准 next-token 预测，无蒸馏、无特殊学习目标。

分阶段训练：后期提高高质量数据权重（借鉴 Gemini）

Gemma 2

2024-06 · 蒸馏引入

目标 = next-token 损失 + 蒸馏损失，学生分布逼近教师全分布。

min Σx −P_T(x|x_c)·log P_S(x|x_c)

Gemma 3

2025-03 · 蒸馏细化

每 token 按教师概率加权采样 256 logits，仅采样集交叉熵；QAT 约 5,000 步。

消融：短视窗小教师更优，长训练大教师更优

Gemma 4

2026-07 · 配方继承

蒸馏配方与 Gemma 3 一致，无新目标函数；工程升级集中在量化与解码。

论文未披露新蒸馏超参细节

—— PART 03 · 指令微调

03 指令微调算法：从数据选择到教师蒸馏

SFT 从"以数据为中心"走向"以蒸馏为中心"：LM 逐对评估选数 → 行为克隆 + on-policy 蒸馏 → 大型 IT 教师蒸馏 → 继承配方并加入思维链数据。

Gemma 1

标准 SFT · 数据驱动

人工 + 合成 prompt-response 对上的标准监督微调。

LM 逐对评估：大模型 judge + CoT / rubrics / constitutions 选数

Gemma 2

行为克隆 + 蒸馏

内部 + 公开提示（LMSYS-chat-1M，不含回答）配合教师合成响应。

学生分布蒸馏（on-policy，Agarwal 2024；Gu 2024）

Gemma 3

大型教师蒸馏

从大型指令微调（IT）教师改进版蒸馏，与 RL 阶段衔接。

论文未披露 SFT 数据具体规模

Gemma 4

继承 + 思维链

SFT 配方同 Gemma 3，新增 thinking mode 推理轨迹数据。

模型先输出推理轨迹，再给出最终答案

—— PART 04 · 强化学习

04 强化学习对齐算法：从偏好对到多奖励

对齐算法从经典 RLHF 出发：奖励模型更大更对话向、阶段模型平均、多奖励融合（人类反馈 + 代码执行 + 数学真实答案），并在 Gemma 4 加入思维链推理轨迹。

Gemma 1

经典 RLHF

人工英文偏好对 + Bradley-Terry 奖励模型 + 未命名新颖 RL 算法。

高容量模型自动评分，缓解奖励黑客

Gemma 2

更大、更对话向

RLHF 算法同 Gemma 1.1；奖励模型比 policy 大一个数量级。

阶段模型平均（WARP / Ramé 2024 思想）

Gemma 3

多奖励融合

基于 BOND、WARM、WARP 的改进版本做 RL 微调。

权重平均奖励模型 + 代码执行反馈 + 数学真实答案

Gemma 4

继承 + 推理轨迹

对齐方案沿用 Gemma 3，未披露新 RL 算法细节。

thinking mode：先推理轨迹、再最终答案

量化感知训练（QAT）

Gemma 3 → Gemma 4

Gemma 3：约 5,000 步，以未量化 checkpoint 概率为目标，支持 int4 与 SFP8。

Gemma 4：mobile（per-channel int2/int4 权重 + int8 激活）与 Q4_0（blockwise + fp16 标量缩放），覆盖图像与音频编码器。

150M 图像编码器 W8A8：内存 400MB→200MB、延迟 −44%；音频编码器磁盘 390MB→87MB（−78%）

推测解码与基础设施

Gemma 4 新增

MTP drafter：4 层 Transformer（256/1024 维，3 local + 1 global）交叉注意力到主模型 KV，省去 prefill；E2B/E4B 用 top-k token cluster 投影（262k→4096）。

TPUv4 / v6e；Slice-Granularity Elasticity：局部故障用更少 slice 续训，中断恢复从数分钟降至数秒

—— PART 06 · 结论

06 三条演进主线与写作建议

训练算法演进可归纳为三条主线，供论文写作直接引用。

1

蒸馏逐步深化

无 → 全词汇概率蒸馏 → 每 token 256-logit 加权采样蒸馏，是预训练算法演进的主干；Gemma 3 给出小/大教师消融结论。

2

后训练走向算法套件

SFT 从数据选择走向行为克隆、on-policy 蒸馏与大型教师蒸馏；RL 从经典 RLHF 走向 BOND/WARM/WARP 改进版与多奖励融合。

3

工程配套并行成熟

QAT、MTP drafter 推测解码与容错训练基础设施（Slice-Granularity Elasticity）成为模型可部署性的关键支撑。

论文写作建议

一是以“蒸馏深化”作为预训练章节主线，重点展开 Gemma 2 的公式与 Gemma 3 的采样设计；二是后训练部分突出“偏好对 → 多奖励 + 思维链”的信号演进；三是 Gemma 1 的新颖强化学习算法未命名、Gemma 4 的算法细节未披露，引用时注明口径，避免过度推断。
