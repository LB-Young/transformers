Gemma 3 家族架构详解

入口类 Gemma3ForCausalLM（270M/1B）/ Gemma3ForConditionalGeneration（4B/12B/27B） 5 个尺寸：270M · 1B · 4B · 12B · 27B 多模态：4B/12B/27B 配 SigLIP 视觉塔（patch 14 · 896px · 256 soft tokens/图） 双 RoPE（global θ=1e6 / local θ=1e4）· 5:1 滑窗/全局交错 · QK-Norm 无 soft-capping（QK-Norm 取代）· 上下文 32K（小）/ 128K（大）

本页以 各变体真实 config.json（本地 gemma-3-270m-it + ModelScope 拉取的 1B/4B/12B/27B）与 transformers 源码 modeling_gemma3.py / configuration_gemma3.py（本地 E:\transformers）为唯一依据。Gemma 3 分两支：纯文本因果 LM（270M/1B，Gemma3ForCausalLM，无视觉塔）与 多模态条件生成（4B/12B/27B，Gemma3ForConditionalGeneration，含 SigLIP 视觉塔）。所有数字均标注来源（config 字段或源码文件:行号）。

1家族全景：五个尺寸的架构对照

270M/1B 为顶层 gemma3_text config（字段全在顶层）；4B/12B/27B 为 gemma3 组合 config，文本栈字段在 text_config 子对象内。4B/12B/27B 的 text_config 只显式列出覆盖默认值的字段，其余（Q/KV 头、head_dim、rope_theta、query_pre_attn_scalar、vocab 等）取 Gemma3TextConfig 默认值，下表逐格标注。

2端到端数据流总览

文本 token 与图像像素两路输入 → 图像经 SigLIP 视觉塔编码、AvgPool + RMSNorm + 线性投影压成 256 soft tokens/图 → 与文本 embedding 一起 masked_scatter 填入图像占位 token 位 → 统一序列 ×√d_model → N 个解码层（sliding 与 full 5:1 交错，双 RoPE）→ 最终 RMSNorm → 共享权重 LM Head（无 softcap）。悬停节点看细节。

全家族统一主干：嵌入(×√d) → 解码层×N → 最终 RMSNorm → 共享 LM Head；差异集中在层数、维度、滑窗窗口、KV 头数，以及是否挂 SigLIP 视觉塔。

3解码层解剖：Gemma 2 式双 RMSNorm 残差块

Gemma 3 的每个解码层（Gemma3DecoderLayer）含两组残差子层：注意力子层与 FFN 子层，均为 pre-norm + post-norm 并用（Gemma 2 起的传统）。全部五尺寸共享此结构，仅维度随尺寸缩放。

4核心机制：双 RoPE · 5:1 交错 · GQA · SigLIP 视觉塔

① 双频率 RoPE（global θ=1e6 / local θ=1e4）

Gemma3RotaryEmbedding 为每种层类型各建一份逆频率表：full 层用 rope_theta=1e6，sliding 层用 rope_local_base_freq=1e4[CFG:99,149-156]。forward 按 layer_type 取对应 {type}_inv_freq[S:161-175]。

inv_freq_i = base ^ (-2i / head_dim), i = 0..(head_dim/2-1) θ_i = pos · inv_freq_i q_rot = q·cos θ + rotate_half(q)·sin θ # full 层 base=1e6（长程）；sliding 层 base=1e4（局部） # 4B/12B/27B 另套 rope_scaling linear factor 8.0（扩 128K）
head_dim：270M/1B/4B/12B=256，27B=128。全维度旋转（无 partial rotary）。

② 每 6 层一个 full（5:1 交错）

层类型由 (i+1) % 6 决定：余数 0 为 full_attention，其余 sliding_attention[CFG:106-112]。Gemma3Attention 据此把 sliding_window 设为窗口值（仅 sliding 层），full 层为 None[S:324-325]。

for i in 0..N-1: type = "full" if (i+1)%6==0 else "sliding" # 270M(N=18): full at 6,12,18 # 1B(N=26): full at 6,12,18,24 # 4B(N=34): full at 6,12,18,24,30 # 12B(N=48): full at 6,12,...,48 # 27B(N=62): full at 6,12,...,60
注意勿套 Gemma 2 的 1:1 交替；Gemma 3 是 5 滑窗 + 1 全局。

③ 滑窗因果掩码 + Hybrid KV cache

文本路建两张掩码：full → create_causal_mask、sliding → create_sliding_window_causal_mask，层循环按 layer_types[i] 取用[S:541-544]。滑窗层只看过去 512（小）/1024（大）个 token，KV cache 对应层只留最近窗口。

M[i,j] = 0 if j ≤ i 且 i - j < sliding_window = -∞ 否则（因果 + 局部） # full 层不受窗口限制，可 attend 到 32K/128K 全长

④ QK-Norm（取代 soft-capping）

Q/K 投影后、RoPE 前各过 Gemma3RMSNorm(dim=head_dim)[S:327-328]。Gemma 3 全家族 attn_logit_softcapping=null、final_logit_softcapping=null——这是与 Gemma 2 的关键差异（官方：以 QK-Norm 取代 soft-capping）。

q = q_norm(q_proj(x)); k = k_norm(k_proj(x)) q,k = apply_rotary_pos_emb(q,k,cos,sin) # norm 在 RoPE 前 # 注意力分数不再 tanh 封顶（softcap 分支因 None 跳过） # scaling = query_pre_attn_scalar^-0.5（270M..12B=1/16；27B=1/√168）

⑤ RMSNorm（零中心 γ）与 GeGLU

RMSNorm 先 fp32 归一，再乘 (1+γ)，γ 初始化为 0[S:139-149]。FFN 为三投影门控 gelu_pytorch_tanh。

rms(x) = sqrt( mean(x²) + eps ) y = ( x / rms(x) ) ⊙ ( 1 + γ ) FFN(x) = down( gelu_tanh(gate(x)) ⊙ up(x) )

⑥ SigLIP 视觉塔 → soft tokens（仅 4B/12B/27B）

图像经 SigLIP ViT 编码后，由投影器压成 mm_tokens_per_image=256 个 soft token，与文本拼接[S:769-770]。

patch: 896/14 = 64 → 64×64 = 4096 patches tokens_per_side = √256 = 16 kernel = 64/16 = 4 → AvgPool 4×4 → 16×16 = 256 soft tokens/图 → RMSNorm(1152) → Linear(1152→text hidden)
视觉塔 config 三支大尺寸完全相同（hidden 1152 / 27 层 / 16 头 / inter 4304 / patch 14 / image 896）。

Gemma 3 的主线升级：① 首次引入 SigLIP 视觉塔成为多模态模型；② 双 RoPE（global 1e6 / local 1e4）+ 5:1 交错滑窗；③ 用 QK-Norm 取代 Gemma 2 的 soft-capping；④ 上下文 8K→32K/128K；⑤ 词表 256K→262144、训练扩到 14T / 140+ 语言。Gemma 2 侧数字为官方公开口径；Gemma 3 侧数字均来自本页 config 与源码。
