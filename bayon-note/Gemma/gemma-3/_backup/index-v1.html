318 层的 full / sliding 布局

config 用 layer_types 显式列出 18 层[C:17-36]；若缺失则由 ("sliding_attention" if bool((i+1)%6) else "full_attention") 生成[CFG:108-112]。即：每 6 层一组，前 5 层滑窗、第 6 层全局。

4单个 DecoderLayer 内部（残差路径 + 注意力细节）

严格对应 Gemma3DecoderLayer.forward[S:388-418]。注意是 Gemma 2 式 pre-norm 与 post-norm 并用：子层输出先过 post-norm 再加残差。

每个解码层含 4 组 RMSNorm：input_layernorm / post_attention_layernorm / pre_feedforward_layernorm / post_feedforward_layernorm[S:383-386]；模型最外层还有第 5 组 norm[S:490]。所有投影 bias=False[C:6]。

6关键机制（含可复算公式）

① 双频率 RoPE（按层类型选 base）

Gemma3RotaryEmbedding 为每种层类型各建一份逆频率表：full 用 rope_theta=1e6，sliding 用 rope_local_base_freq=1e4[CFG:149-156]。forward 时按 layer_type 取对应 {layer_type}_inv_freq[S:205-206]。

inv_freq_i = base ^ (-2i / d_head), i = 0..127 θ_i = pos · inv_freq_i q_rot = q·cos θ + rotate_half(q)·sin θ
full 层 base=1e6（长程），sliding 层 base=1e4（局部）。d_head=256[S:196]

② 每 6 层一个 full（5:1）

层类型由 (i+1) % 6 决定：余数为 0 即第 6/12/18 层为 full_attention，其余 15 层为 sliding_attention[CFG:108-112]。Gemma3Attention 据此把 sliding_window 设为 512（仅滑窗层），否则为 None[S:324-325]。

for i in 0..17: type = "full" if (i+1)%6==0 else "sliding" → full at layers 6,12,18

③ 滑窗因果掩码

文本路建两张掩码字典：full_attention → create_causal_mask、sliding_attention → create_sliding_window_causal_mask，每层按类型取用[S:541-544]。滑窗层中 token i 只能看过去窗口内的 token。

M[i,j] = 0 if j ≤ i 且 i - j < 512 = -∞ 否则（因果 + 局部）
全局层不受 512 限制，可attend最长 32K

④ QK-norm（逐头 RMSNorm）

Q/K 投影后、RoPE 之前，各过一组 Gemma3RMSNorm(dim=head_dim=256)[S:327-328]。配合 270M 的 null softcap：注意力分数不做 tanh 封顶[S:281-284]。

q = q_norm(q_proj(x)); k = k_norm(k_proj(x)) q,k = apply_rotary_pos_emb(q,k,cos,sin) # norm 在 RoPE 前

⑤ RMSNorm（零中心 gamma）

Gemma 变体 RMSNorm：先 fp32 归一，再乘 (1+γ)（γ 初始化为 0，即零中心）[S:135-149]。

rms(x) = sqrt( mean(x²) + eps ) y = ( x / rms(x) ) ⊙ ( 1 + γ )
eps=1e-6；QK-norm 作用于 head_dim=256，层 norm 作用于 d=640

⑥ GeGLU 前馈

三投影门控 FFN，激活为 GELU 的 tanh 近似[S:119-132]。

FFN(x) = down_proj( GELU_tanh(gate_proj(x)) ⊙ up_proj(x) ) 640 → 2048 → 2048 → 640
gate/up/down 全部 bias=False

⑦ 嵌入缩放 √d

embed_tokens 不是普通 Embedding，而是 Gemma3TextScaledWordEmbedding，输出乘 √d_model=√640≈25.30[S:105-116]。

e = Embedding[input_ids] · sqrt(640)

⑧ Hybrid KV cache

默认 use_cache=True，前向首次创建 DynamicCache(config)[S:516-517]。滑窗层的 cache 单元只保留最近 sliding_window 个 token（keys = keys[:,:,-511:,:]），全局层保留全历史——这就是“hybrid”：层间 cache 容量按层类型异构[CU:243-246]。每层更新：past_key_values.update(k,v,layer_idx)[S:351-352]。

15 个滑窗层 KV 上限 ≈ 512·2·1·256；3 个全局层随序列增长
