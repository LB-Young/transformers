Gemma 1 家族架构详解（2B / 7B）

2024-02 发布 · 纯解码器 · 稠密 入口类 GemmaForCausalLM 本地 config：gemma-2b-it（unsloth 转换版） 2B：MQA（1 KV 头 → 广播 8 倍） 7B：MHA（16 KV 头 = 16 Q 头）

Gemma 1 是 Google 基于 Gemini 研究技术的首个开放权重模型家族，纯解码器 Transformer[P]。本页以本地 gemma-2b-it 的 config.json、ModelScope 多镜像核验的 gemma-7b(-it) config.json，以及本地 transformers 源码 modeling_gemma.py / configuration_gemma.py（v5.5.0.dev0）为唯一依据。一个常被忽略的事实：家族内 2B 用 MQA（1 个 KV 头），7B 用完整 MHA（16 个 KV 头）——两者的 KV 缓存策略并不相同。所有数字均标注来源（config 字段或源码 文件:行号）。

2端到端数据流总览（以本地 2B 为主尺寸）

输入 token id → 缩放词嵌入（×√d_model，tied）→ 18 个相同的 GemmaDecoderLayer → 最终 RMSNorm → 无 bias 线性 lm_head（与嵌入共享权重）→ logits。7B 同构，仅把 18 层换成 28 层、维度换成 3072/4096。悬停/点击节点看细节与源码行号。

数据流与源码逐项对应：嵌入 embed_tokens（:362）→ 逐层 for decoder_layer in self.layers（:414-423）→ self.norm（:424）→ lm_head（:491）。因果掩码由 create_causal_mask 统一构造（:402-408）。

3单个 GemmaDecoderLayer 解剖（以 2B 为例）

严格按 GemmaDecoderLayer.forward（:305-324）与 GemmaAttention.forward（:254-281）绘制。橙色虚线 = 残差捷径；青色 = K/V 路径（2B 的 MQA 广播）。所有 Linear 均 bias=False。注意每层只有 2 个 RMSNorm（input_layernorm + post_attention_layernorm），没有 Gemma 2 的 post-feedforward norm。

层内执行顺序（GemmaDecoderLayer.forward :305-323）：

residual = x x = input_layernorm(x) x = self_attn(x); x = residual + x residual = x x = post_attention_layernorm(x) x = mlp(x); x = residual + x

即两个 pre-norm + 两个残差。与 Gemma 2 的关键差别：Gemma 1 在 FFN 之后没有第二次归一化（post_feedforward_layernorm），这是 Gemma 2 引入的"双归一化"（§7）。

4核心机制专节（含可复算公式与源码行号）

4.1 RMSNorm（pre-norm，Gemma 变体）

对子层输入做 RMSNorm，共 3 处：注意力前（input_layernorm）、FFN 前（post_attention_layernorm）、全部层后（model.norm）。

rms(x) = x · rsqrt( mean(x²) + eps ) # :70 y = rms(x.float()) · (1.0 + weight) # :73-76
eps=1e-6；Gemma 特有：缩放项是 (1+weight) 而非 LLaMA 的 weight，weight 初始化为 0（:67）；先 fp32 归一化再乘权重后回落到原 dtype（:73,77）。

4.2 MQA（2B：单 KV 头广播）

2B 的 8 个 query 头共享 1 组 K/V：K、V 投影只产出 1×256，打分前用 repeat_kv 复制成 8 份对齐 8 个 Q 头。

groups = num_q_heads // num_kv_heads = 8 // 1 = 8 # :225 (b,1,s,256) --expand--> (b,8,s,256) # :187-188
KV cache 体积仅为 8 头 MHA 的 1/8，降低推理带宽与显存。7B 不做此广播：groups=1，repeat_kv 在 n_rep==1 时直接 return（:185-186），是完整 MHA。

4.3 GeGLU 门控前馈

双投影门控结构，激活取门控分支后与另一分支逐元素相乘：

y = down_proj( act(gate_proj(x)) ⊙ up_proj(x) ) # :95 2B: 2048→16384 → ⊙ → 16384→2048 7B: 3072→24576 → ⊙ → 24576→3072
激活口径：config 原文 hidden_act="gelu"，经 ACT2FN[config.hidden_act] 映射（:92）。注意新版 configuration_gemma.py:90-95 会对 legacy "gelu" 告警并改写为 "gelu_pytorch_tanh"（注释称旧官方发布值本意指向 tanh 近似）——本页以 config 原文为准并并列标注此口径。

4.4 RoPE（旋转位置编码，θ=10000）

每层对 Q、K（不对 V）施加旋转；θ=10000，作用维度 = head_dim = 256。

inv_freq = 1 / ( base ^ (2i / head_dim) ) # :132, base=θ :127 q' = q·cos + rotate_half(q)·sin # :174
旋转方式为 rotate_half（半切式，LLaMA 风格）：把 head_dim=256 切成前后各 128 维，cat(-x₂, x₁)（:146-150）。cos/sin 在 GemmaModel.forward 统一算一次后传入各层（:412）。

4.5 嵌入缩放与权重绑定

GemmaTextScaledWordEmbedding.forward 在查表后乘 embed_scale = √hidden_size（2B √2048≈45.25；7B √3072≈55.43，:60,:363）——Gemma 相对 LLaMA 的易忽略细节。同时 lm_head.weight 与 embed_tokens.weight 绑定共享（:433,:442）。

缩放补偿 RMSNorm 支路与残差叠加的尺度，使训练更稳；绑定权重把 256k 词表的巨大嵌入参数摊薄。

4.6 注意力打分数值细节

缩放系数 scaling = head_dim⁻⁰·⁵ = 256⁻⁰·⁵ = 1/16 = 0.0625（:226）；QKᵀ 加因果掩码后，softmax 在 fp32 计算（:208）再回落 dtype；eval 无 dropout（:274）。全程无 attention / logit soft-capping。

因果掩码由 create_causal_mask 统一构造（:402-408）。

5注意力机制：2B 的 MQA vs 7B 的 MHA

Gemma 1 家族两个尺寸的注意力结构同构（Q/K/V/O 四投影 + RoPE + 因果掩码 + fp32 softmax），唯一实质差别在 KV 头数：小模型 2B 用 MQA 压缩 KV，大模型 7B 保留完整 MHA。

7演进视角：Gemma 1 → Gemma 2

Gemma 1 是系列第 1 代基线。Gemma 2（2024-06）在保留 pre-norm + GeGLU + RoPE + RMSNorm 母版的同时，引入若干关键结构增量。下表 Gemma 1 列为本页 config 实测，Gemma 2 列为官方口径（技术报告 arXiv:2408.00118 与模型卡 model_card_2）。

维度Gemma 1（2B / 7B）Gemma 2（官方口径）
尺寸2B（≈2.6B）/ 7B（≈8.5B）2B / 9B（42 层）/ 27B（46 层）
注意力分组2B：MQA（1 KV 头）；7B：MHA（16 KV 头）统一 GQA：2B 8Q/4KV，9B 16Q/8KV，27B 16Q/8KV
滑动窗口无（全局全注意力）sliding_window=4096，与全注意力层交错
归一化每层 2 个 RMSNorm（input + post-attn）双归一化：新增 post_attention / post_feedforward 旁路 norm
soft-capping无attention logit soft-capping（50.0）+ 最终 logit soft-capping（30.0）
query 缩放scaling = head_dim⁻⁰·⁵（=1/16）引入 query_pre_attn_scalar，可与 head_dim 解耦
上下文81928192（与 Gemma 1 相同）
训练数据2B≈3T / 7B≈6T（论文 §4.2）2B 2T（蒸馏）/ 9B 8T（蒸馏）/ 27B 13T（从零）

演进主线：Gemma 1 是 pre-norm + GeGLU + RoPE(θ1e4) + RMSNorm 的解码器母版，2B 用 MQA 压缩 KV；Gemma 2 把 KV 分组收敛为统一 GQA，并叠加 sliding window、双归一化与 soft-capping，规模扩到 27B。这些增量（GQA / sliding / softcap / 双 norm）正是对比 Gemma 1 页时的主要论点。
