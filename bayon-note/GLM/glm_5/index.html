GLM-5 家族架构详解 — GLM-5（744B-A40B DSA/MTP）· 5.2 · 5.3-Flash（glm5_next）

GLM-5.3-Flash 落地：Glm5NextForConditionalGeneration（model_type=glm5_next） GLM-5 本体：744B/40B · 256 专家 top-8 · 78 层 · 202,752 · MLA+DSA+MTP 官网口径 745B/44B/5.9% sparsity（glm5.ai，差异口径） GLM-5.2：1M · IndexShare（FLOPs↓2.9×）· MTP +20% 5.3-Flash：320B/18B · 45 层 · 288 专家 · KDA×34+DSA×11 · mHC · 原生多模态

本页以 GLM-5 技术报告（arXiv:2602.15763）+ glm5.ai + docs.bigmodel.cn + z.ai/blog/glm-5.2 + NVIDIA NIM + 本地 transformers 源码 models\glm5_next\ 为唯一数据源。口径声明：本地无 GLM-5 checkpoint/config 留档，GLM-5 本体规格以技术报告/官方文档/官网为准；glm5_next 源码 = GLM-5.x 家族在 transformers 的落地实现（对应 GLM-5.3-Flash 架构），不是 GLM-5 本体的实现；本地无法核实处标注「待核实，以官方发布为准」。

2端到端数据流总览

文本 token + 图像/视频 → vision encoder（Glm5NextVisionModel：24 层/1024/patch14·336/merge2/out1536，≈144 token/图）→ soft 特征按 image_token(154854)/video_token(154855) masked_scatter 进序列 → 文本解码栈 → HyperHead 4 流均值 → RMSNorm → LM Head；另有 MTP 头。多模态细节全部来自 glm5_next（=5.3-Flash 落地实现）；GLM-5 本体以文本/Agentic 为主线。

3解码层解剖：以 glm5_next 源码为准（GLM-5.3-Flash 架构落地实现）

本节解剖对象 = GLM-5.x 家族在 transformers 的落地实现（对应 GLM-5.3-Flash 架构），不是 GLM-5 本体。Glm5NextTextDecoderLayer（mdl-S:1279-1349）用 mHC 4 流残差：attn/ffn 两侧各做「4 流 collapse → 子层 → post·out + combᵀ·residual 恢复」；注意力按 idx 分流（%4==3 → DSA，其余 → KDA）；FFN 前 3 层 dense、后 42 层 MoE。

Glm5NextTextDecoderLayer.forward（mdl-S:1313-1349）: residual = hidden_states # mHC 4 流 [B,S,4,4096] [S:1313] post, comb, hidden = attn_hc(...) # 4 流→单流 collapse [S:1314] hidden = input_layernorm(hidden) # RMSNorm [S:1316] if idx % 4 == 3: out,w,topk = indexed_attention(...) # DSA [S:1326-1335] else: out = linear_attention(...) # KDA [S:1318-1324] hidden = post*out + combᵀ @ residual # 恢复 4 流 [S:1336-1338] residual = hidden_states post, comb, hidden = ffn_hc(...) # 再次 collapse [S:1341] hidden = post_attention_layernorm(hidden) # [S:1343] out = mlp(hidden) # dense(前3层)/MoE(后42层) [S:1344] hidden = post*out + combᵀ @ residual # [S:1345-1347] return hidden, topk_indices # [S:1349]

4核心机制专节：DSA · MTP · MoE 路由 · MLA/mHC

① DSA 稀疏注意力

GLM-5 从稠密 base 两阶段 continued pre-training（dense warm-up + sparse adaptation，20B@200K）适配 DSA：内容相关 top-k，indexer 检索 k=2048（32 头×128）；长序列算力降 1.5–2×，报告称 90% 长上下文注意力冗余。本地落地为 pool=16 的 block 级稀疏（ReLU 打分 → top-128 池 → 2048 token → 3D mask → SDPA，不支持 FA）。

跨层共享 indexer（shared 层 indexer=None 复用前层 top-k，mdl-S:1150-1154）= GLM-5.2 IndexShare 的代码对应（每 4 层共享，1M FLOPs ↓2.9×）。昇腾侧：Lightning Indexer / Sparse Flash Attention / MLAPO。5.9% sparsity 仅 glm5.ai 官网口径，报告未给出。

scores = relu(q · pool_kᵀ · scale) # @no_grad [mdl-S:862-863] select_k = index_topk / index_kpool = 2048 / 16 = 128 池 # [mdl-S:884] 展开 → 2048 token + tail(≤+15) → pad -1

② MTP（多 token 预测）

GLM-5 训练参数共享 3 个 MTP 层，部署 1 层（Table 10）；同 4 步投机接受长度 2.76 vs DeepSeek-V3.2 的 2.55。GLM-5.2 再 +20%：base 4.56 → +IndexShare+KV Share 5.10 → +Rejection Sampling 5.29 → +E2E TV Loss 5.47。

旁证：transformers 未实现 MTP——_keys_to_ignore_on_load_unexpected 显式忽略 layers.45.* / layers.*.shared_head.*（mdl-S:1379），主输出仅 lm_head（mdl-S:2150,2258）。

接受长度：GLM-5 = 2.76 vs DSv3.2 = 2.55 GLM-5.2：2.76 → +20%（消融 4.56 → 5.47） 训练：共享 3 层 · 部署：1 层

③ MoE 路由：sigmoid + norm_topk + scaling 2.5

Glm5NextTextTopkRouter（mdl-S:144）与 GLM-4.5 血统一致：sigmoid 打分（非 softmax） → 组内 top-k → 按行归一 → 乘 routed_scaling_factor=2.5。MoE 容器 = 288 路由专家 top-8 + 1 共享专家（全 token 激活）；aux_loss 权重 0.001。

w_i = sigmoid(router(x)_i) + b_i, i ∈ top_8(x) w̃_i = w_i / Σ_top8 w_j × λ λ = 2.5 FFN_MoE(x) = Σ_top8 w̃_i·E_i(x) + Shared(residuals)

④ MLA 与 mHC

MLA：GLM-5 以 MLA 为注意力基座（Q LoRA 2048 / KV LoRA 512 / 64 头 / QK dim 192 / V dim 256），配 Muon Split 与 MLA-256 变体；glm5_next 落地 q_lora 1536 / kv_lora 512，KV cache 写在压缩 latent 层。mHC：hc_mult=4 流残差贯穿每层 attn/ffn 两侧，Sinkhorn 归一化 comb（20 迭代），HyperHead 4 流 mean 折叠；文本侧 NoPE。

MLA：q_a_proj(1536) → q_b_proj kv_a_proj_mqa(→512) → kv_b_proj mHC：hidden = post·out + combᵀ·residual comb ~ Sinkhorn(4×4) · hc_mult = 4

5异步 RL 训练（Slime）与 Agentic Engineering

28.5T tokens 训练预算配比

通用语料 18T + 代码&推理 9T（=27T 预训练）→ 长代码&推理 1T（32K）→ 长上下文&Agent 500B/50B（128K/200K）→ DSA 适配 20B（200K）。Post-training：Overall SFT → Reasoning RL → Agentic RL → General RL + On-Policy Cross-Stage Distillation。

28.5T = 18T 通用 + 9T 代码推理 + 1T 长代码 + 500B/50B 长上下文 + 20B DSA 适配

slime 异步 RL 框架

全异步解耦 rollout/训练；Multi-Task Rollout Orchestrator 1k+ 并发 rollout；TITO Gateway；Direct Double-sided Importance Sampling；DP-aware routing；FP8 rollout + PD 分离。GLM-5.2 用 slime 并行 OPD 约两天合并十余专家模型。

Agentic Engineering（§4）

10,000+ 可验证 SWE 环境（9 种语言）；Harbor terminal 环境（Docker 准确率 >90%）；搜索任务基于 200 万+ 网页 Web Knowledge Graph。另：INT4 QAT；首日适配 7 国产 GPU 平台（昇腾/摩尔线程/海光/寒武纪/昆仑芯/沐曦/燧原）。
