3解码层解剖

x = RMSNorm(x) a = SelfAttn(QKV_bias, kv_groups=2, rope=1d) x = x + a # post_layer_norm x = RMSNorm(x) x = x + SwiGLU(x) # ffn 13696

4核心机制

① MQA/GQA

32 Q 头共享 2 组 KV，KV cache 降为 1/16；官方称推理提速约 42%。

② RMSNorm+SwiGLU

rmsnorm=true 取代 LayerNorm；ffn 13696≈10/3·4096 补偿 GQA 减参。

③ 1D-RoPE

original_rope=true，移除 ChatGLM-6B 的 2D-RoPE。

④ 上下文

ChatGLM2 config=32768（FlashAttention 32K）；ChatGLM3 config=8192。
