CLIP 家族架构详解

研读对象 models/clip/（transformers 5.23.0.dev0）。CLIP 是 OpenAI 2021 年的双塔视觉语言模型：图像与文本各自编码到同一向量空间，用对比学习对齐，以 4 亿网络图文对为监督，训练出可零样本迁移的视觉模型——零样本分类、图文检索、图文相似度的标准范式。现代多模态 LLM 的视觉塔大多直接或间接继承自 CLIP。

1一句话定位

CLIP（Contrastive Language-Image Pre-training，arXiv:2103.00020）核心主张：图像和文本各自编码到同一个向量空间，用对比学习对齐，以 4 亿（400M）网络图文对为监督，训练出可零样本迁移的视觉模型。

4端到端双塔架构总览

视觉塔把 224×224 切成 7×7=49 个 32×32 patch + CLS → 12 层双向 Transformer → 池化取 [CLS]；文本塔 BPE 分词 → 12 层因果 Transformer（GPT-2 式）→ 池化取 [EOS]。两塔投影到 512 维公共空间做对比。

5核心机制（对照代码）

5.1 双塔各自编码

视觉塔（CLIPVisionModel :585）：CLIPVisionEmbeddings 把 224×224 切成 32×32 patch（49 个）拼上 CLS token → 12 层双向 Transformer → 池化取 [CLS] 状态（:630 docstring「pooled CLS states」）。

文本塔（CLIPTextModel :485）：BPE 分词 → 位置编码 → 12 层因果 Transformer（GPT-2 式）→ 池化取 [EOS]（最后一个 token）状态（:524 docstring「pooled (EOS token) states」）。

5.2 投影与相似度（CLIPModel :651）

image_embeds = visual_projection(pooler_output)   # 768 → 512
text_embeds  = text_projection(pooler_output)     # 512 → 512
两者 L2 归一化 → 余弦相似度矩阵 × logit_scale
# logit_scale 是可学习参数，初始 2.6592 ≈ ln(1/0.07)

5.3 对比损失（InfoNCE）

对 batch 内每张图：拉近正样本对 (I_i, T_i)，推远 batch 内其余文本 (I_i, T_j) 作为负样本；对称地也以文本为锚。不做显式 hard-negative 挖掘，靠大 batch 提供负样本。

5.4 图像预处理

image_processing_clip.py：resize（保持比例）→ center_crop(224) → ImageNet 均值/方差归一化——与训练口径严格一致。

6训练方法（论文层面）

要素要点
数据4 亿（400M）从互联网收集的图文对，天然带噪声但规模巨大
目标对称对比损失（InfoNCE），batch 极大（论文以 32768 级 batch 训练）
可学习温度logit_scale 随训练调整，避免人为设定 softmax 温度
零样本迁移分类时把类别名拼成「a photo of a {label}」模板输入文本塔，取与图像特征相似度最高者

一分钟结论

维度要点
架构视觉塔 ViT-B/32（12L/768/12H）+ 文本塔 Transformer（12L/512/8H）双塔
对齐投影到 512 维公共空间，L2 归一化 + 余弦相似度 × logit_scale
损失对称 InfoNCE 对比损失，正对拉近 / 负对推远
池化视觉取 [CLS]，文本取 [EOS]
预训练数据4 亿网络图文对
代码入口CLIPModel / CLIPTextModel / CLIPVisionModel / *WithProjection / CLIPForImageClassification

与多模态 LLM 的关系：LLaVA、BLIP-2、InstructBLIP、MiniGPT-4 等第一代多模态 LLM 直接借用 CLIP 视觉塔（通常 ViT-L/14@336）；SigLIP 用逐对 sigmoid 损失替代 CLIP 的 softmax 对比损失；BLIP 的 ITC 目标即 CLIP 式对比。CLIP 是「图文对比预训练视觉编码器」谱系的原点。
