SigLIP vs SigLIP 2 架构详解

研读对象 models/siglip/（v1）与 models/siglip2/（v2），transformers 5.21.0.dev0。SigLIP 是 Google 的视觉语言双塔编码器，核心用逐对 sigmoid 损失替代 CLIP 的 softmax 对比损失；SigLIP 2 引入 NaFlex 原生灵活分辨率与更强训练目标。视觉塔被大量多模态 LLM（含 Gemma 3）直接借用。

1一句话定位

SigLIP 1（2023，arXiv:2303.15343）：固定分辨率（默认 224×224 → 14×14=196 patch），learned 位置嵌入，sigmoid 损失训练更稳、收敛更快。

SigLIP 2（2025，arXiv:2502.14786）：NaFlex 原生灵活分辨率（单 checkpoint 支持任意宽高比/分辨率，≤256 patch），训练目标叠加 decoder loss + global-local / masked prediction，多语言 + 去偏数据。

2源码模块与类关系

两个版本是独立模块，但 v2 的类全部继承 v1；文本侧 v2 与 v1 结构完全一致（继承、无重写）——差异全部集中在视觉塔。

4视觉塔实现对比（核心机制）

4.1 位置嵌入：固定扁平 vs 16×16 网格插值

SigLIP 1（SiglipVisionEmbeddings，modeling_siglip.py:116）

  • patch_embedding = nn.Linear(3×16×16, 768)
  • position_embedding = nn.Embedding(196, 768)（224/16=14 → 14×14=196，扁平索引）
  • forward：embeddings = inputs_embeds + position_embeddings（纯加性，位置网格固定）

SigLIP 2（Siglip2VisionEmbeddings，modeling_siglip2.py:114）

  • patch_embedding 同上
  • position_embedding = nn.Embedding(256, 768) —— 看作 16×16 的 2D 位置网格（position_embedding_size = sqrt(256) = 16）
  • forward 调用 resize_positional_embeddings（:130）

4.2 forward 签名与 padding 掩码

SiglipVisionModel.forwardSiglip2VisionModel.forward
输入pixel_values（固定 (B,3,H,W)）pixel_values（已 patchify，(B,256,…)）+ pixel_attention_mask + spatial_shapes
掩码无需create_bidirectional_mask 按像素掩码遮掉 padding patch
输出last_hidden_state + pooler_output同左

4.3 共享结构（两版相同）

双向注意力 Encoder（SiglipEncoderLayer / Siglip2EncoderLayer，均 12 层）、post_layernorm、MHA pooling head（SiglipMultiheadAttentionPoolingHead，use_head 可关，vision_use_head 控制）——视觉塔输出用多头注意力池化聚合，而非 CLIP 式的取 CLS。

5训练方法对比（论文层面）

5.1 SigLIP 1（arXiv:2303.15343）

对 batch 内 (图像, 文本) 每对独立计算：
loss = log(1 + exp(-y · (sim · t + b)))
# 不做 softmax 归一化 —— 摆脱负样本 pair 之间的耦合
# t：可学习温度，初始 log(10)
# b：可学习偏置，初始 -10（BiC 偏置校正初始化）
#   —— 负样本对远多于正样本，先压低所有 logit，避免初期大步纠偏

5.2 SigLIP 2（arXiv:2502.14786）

在 SigLIP 对比目标之上叠加：

训练目标说明
decoder loss解码器重建图像 patch，辅助密集特征
global-local / masked prediction全局-局部一致性 + 掩码预测，提升定位/局部语义（检测、分割类任务）
NaFlex 训练训练时混用多分辨率/多宽高比，位置嵌入插值
多语言 + 去偏过滤WebLI 数据上多语言训练 + debiasing 过滤，跨文化语义更均衡
注意：decoder / masked 分支是训练期目标，HF 发布的推理模型只有「文本塔 + 视觉塔 + 对比头」结构，不含这些训练分支。

一分钟结论

维度SigLIP 1SigLIP 2
分辨率固定（224/384）NaFlex 灵活（≤256 patch，保宽高比）
位置嵌入固定扁平 learned（加性）16×16 网格 learned + 双线性插值 + 边界复制 pad
输入原始图 (B,3,H,W)patchify 序列 + pixel mask + spatial_shapes
训练目标sigmoid 对比 + t/b 初始化+ decoder loss + masked prediction + 多语言去偏
文本塔12L/768/12H完全相同（继承）
输出池化MHA pooling headMHA pooling head（同）

与多模态 LLM 的关系：Gemma 3 视觉编码器即 SigLIP-2 变体（400M 级）；InternVL 视觉塔与 SigLIP 同源思路；Qwen2-VL 视觉塔为自研 ViT（非 SigLIP 实现）但可变分辨率思路与 NaFlex 一致；后续工作 SigLIP-HD 用 SigLIP 2 多尺度教师蒸馏标准分辨率学生。
